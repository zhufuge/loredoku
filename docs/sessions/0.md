
写一个类地图编辑器的需求文档，使用技术栈为nodejs+ts+vite, 后端koa+postgresql，前端react+shadcn/ui+taiwindcss。
主要功能是将有特定图案的方块卡片拖到在一个n*n的方格中。
需求：
1. 有地图项目管理列表，有管理相关功能，创建时填写相关信息如n的值。
2. 有卡片管理功能，有名称，id，关联信息（通过信息触发如高亮等功能），可上传图片，图片保存在后端文件系统中通过数据库信息找到。
3. 编辑器页面有左边卡片选择区等工具功能，右边大部分是方格区，卡片可拖入方格。有保存功能，记录方格的卡片id等信息。
4. 编辑器有选定一片（多个方块）区域的功能，并给这块区域进行标记，标记时填写名称等信息，用于触发区域高亮，区域的边界使用比方块间边界更粗的线条。

项目文件名为murdoku-maker
n不大于24.
