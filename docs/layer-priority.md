# 画布图层优先级规范

**文档类型**：画布渲染次序的规范性定义（唯一权威）
**适用范围**：编辑器画布（`/editor/:projectId`）与作品预览页（`/works/:workId/view`）
**版本**：v0.3.8（自 v0.3.4 OPT-901 起持续修订）
**实现载体**：`packages/shared/src/constants.ts` 的 `MAP_LAYER_ORDER` / `MAP_LAYER_Z`

---

## 1. 术语约定

本规范对每一层的命名做如下统一。文中出现「上方 / 下方」时，**一律指视觉叠放次序**
（上方 = 更靠近观察者 = 更大的 CSS `z-index`），与文档排版方向无关。

| 层号 | 规范名称 | 英文标识（代码常量名） | 定义 |
|---|---|---|---|
| 1 | 当前鼠标所在框 | `cellMouseCursor` | 跟随指针移动的方格提示框，标示指针当前所指方格 |
| 2 | 当前操作方格框 | `cellOperationCursor` | 固定在「当前操作方格」上的提示框，标示最近一次点击选中的方格 |
| 3 | 区域名称 | `regionLabel` | 区域名称文字（含字色与描边） |
| 4 | 物体 | `object` | **物件层**物品的图片 |
| 5 | 地图最外边框 | `canvasFrame` | 整张画布最外圈的边框线 |
| 6 | 边框 border | `gridBorder` | 方格之间的内部分隔线 |
| 7 | 区域边界线 | `regionEdge` | 区域外轮廓描线 |
| 8 | 不可站立物体阴影 | `noStandShadow` | 标示「该格物品不可站立」的半透明蒙版 |
| 9 | 区域高亮线 | `regionHighlight` | 区域被悬停或联动激活时出现的内侧高亮线 |
| 10 | 方块高亮 | `cellHighlight` | 联动激活时覆盖**整格**（含背景层）的不透明色块 |
| 11 | 背景高亮 | `backgroundHighlight` | 联动激活时**仅替换背景层**的色块 |
| 12 | 背景 | `background` | **背景层**物品的图片 |
| 13 | 空方格 | `emptyCell` | 画布底色（未被任何图层覆盖时的基础面） |

> 另有 **区域填充**（`regionFill`）为 v0.2.5 遗留图层，未纳入本表，固定置于 `background` 之上、
> `backgroundHighlight` 之下（`z-index = 22`）。新增图层必须登记进本表，不得使用表外 z-index。

## 2. 优先级次序（唯一权威）

由高到低：

```
当前鼠标所在框
  > 当前操作方格框
    > 区域名称
      > 物体
        > 地图最外边框
          > 边框 border
            > 区域边界线
              > 不可站立物体阴影
                > 区域高亮线
                  > 方块高亮
                    > 背景高亮
                      > 背景
                        > 空方格
```

单行形式（便于对照代码）：

```
当前鼠标所在框 > 当前操作方格框 > 区域名称 > 物体 > 地图最外边框 > 边框 border > 区域边界线 > 不可站立物体阴影 > 区域高亮线 > 方块高亮 > 背景高亮 > 背景 > 空方格
```

**z-index 取值**

| 层号 | 层名 | z-index |
|---|---|---|
| 1 | 当前鼠标所在框 | 46 |
| 2 | 当前操作方格框 | 45 |
| 3 | 区域名称 | 42 |
| 4 | 物体 | 40 |
| 5 | 地图最外边框 | 39 |
| 6 | 边框 border | 38 |
| 7 | 区域边界线 | 36 |
| 8 | 不可站立物体阴影 | 35 |
| 9 | 区域高亮线 | 32 |
| 10 | 方块高亮 | 30 |
| 11 | 背景高亮 | 28 |
| 12 | 背景 | 20 |
| 13 | 空方格 | 10 |
| — | 区域填充（表外遗留） | 22 |

编辑器专属的拖拽 / 框选反馈（框选矩形、区域草稿单元格、未落位物品预览）挂在第 1 层**之下的**
临时层（`cellMouseCursor − 1` / `− 2`），属于编辑器 affordance，不属于本规范的 13 层。

## 3. 各层行为定义

### 3.1 当前鼠标所在框（层 1）

- 跟随指针实时移动；指针离开画布即消失；
- 由**内描边**构成，线宽与颜色取自地图基本信息；指针所指方格存在「不可站立物体」时改用
  「被阻挡颜色」；
- 另叠加一圈半透明阴影环覆盖 `边框 border`，使框线在深色网格上仍然可辨；
- 为画布**最高层**：任何情况下都不得被其它图层遮挡。
- 数值来源：`style.mouseCursor.width / color / blockedColor / shadowColor`。

### 3.2 当前操作方格框（层 2）

- **固定在「当前操作方格」**（最近一次点击选中的方格），不随指针移动；
- 点击另一格即移动到该格；点击画布外空白或按 `Esc` 即消失；
- 以 **Outline（外描边）** 形式绘制在 `边框 border` **外侧**，不参与布局计算；
- 恒位于层 1 之下：二者落在同一格时，鼠标框的线在内、操作框的线在外，形成可分辨的双层框。
- 数值来源：`style.operationCursor.width / color / offset`。

### 3.3 区域名称（层 3）

- 文字位于**物体之上**，任何物品图都不得遮挡区域名称；
- 位于**地图最外边框之上**，不被最外边框压住；
- 采用「描边 + 填充」绘制（描边在下、填充在上），保证在深浅背景上都可读；
- 区域被悬停或激活时，切换到「高亮字体颜色 / 高亮描边颜色」；
- 区域名称可接收指针事件（用于悬停与点击）；其余绘制层一律不接收指针事件。

### 3.4 物体（层 4）

- **物件层**物品的图片；
- 位于**边框 border 之上**：网格线不得切断物品图；
- 位于**地图最外边框之上**：最外边框不得遮挡物品图；
- 图片被裁剪在其占位矩形内部，并在占位矩形四周保留内边距；
- 多格物品的图片按其**整体占位矩形**绘制，而非逐格绘制。

### 3.5 地图最外边框（层 5）

- 整张画布的外圈边框，线宽为地图基本信息配置值；
- **绘制在画布矩形之外**（以半线宽向外偏移），因此与格内任何内容**几何上不重叠**；
- 位于**物体之下**：即使内容贴边，也不遮挡物品图；
- 位于**边框 border 之上**：与内部分隔线交会处由最外边框占优，避免视觉上的「重叠加粗」。
- 数值来源：`style.canvasFrame.width / color`。

### 3.6 边框 border（层 6）

- 方格之间的**内部分隔线**；相邻两格**共享同一条**线，因此 `n × n` 的画布共有 `n − 1` 条横线
  与 `n − 1` 条竖线，严禁每格绘制四条边；
- 位于**区域边界线之上**：区域边界线不得盖住网格，保证方格划分始终清晰；
- 不接收指针事件。
- 数值来源：`style.border.width / color`。

### 3.7 区域边界线（层 7）

- 区域外轮廓的描线，线宽取**区域自身配置值**（由地图基本信息的缺省值初始化）；
- 位于**边框 border 之下**、**不可站立物体阴影之上**；
- 相邻区域交界处由两个区域各自绘制一条线，**不做合并、不做取舍**，交界处较粗为预期表现；
- 颜色由地图基本信息统一决定。
- 数值来源：`style.regionBorder.color`（全局） + `region.borderWidth`（逐区域）。

### 3.8 不可站立物体阴影（层 8）

- 当某格物件层物品的 `canStand = false` 时，对该格叠加半透明蒙版；
- 位于**区域边界线之下**、**区域高亮线之上**；
- 蒙版矩形内缩至 `边框 border` 内侧，不覆盖网格线；
- 物品图本身位于本层之上，因此物件层物品会在蒙版上方显示；由于物品图带有内边距（四周留白 2 ~
  12px），蒙版仍可在物品图四周的留白处被看到，提示作用保留；
- 物品被停用或删除时视为「可站立」，不再绘制阴影；修改物品的 `canStand` 设置即时生效，
  **不会删除任何格子内容**。

### 3.9 区域高亮线（层 9）

- 区域被悬停 / 联动激活时出现，绘制在**区域边界线内侧**并向内扩展，不遮住区域边界线；
- 位于**方块高亮之上**：整格色块不得盖住区域轮廓提示；
- 几何必须严格水平或垂直（由纯函数生成，禁止手工端点偏移）；
- 区域被激活期间**常亮**，激活结束时以 150ms 淡出。
- 数值来源：`style.regionHighlight.width / color`。

### 3.10 方块高亮（层 10）

- 联动激活时，对目标方格绘制**不透明**色块，覆盖**整格**（含背景层）；
- 多格物品的方块高亮展开到其**全部占位格**；
- 位于**背景高亮之上**、**区域高亮线之下**；
- 颜色取联动配置所引用的**主题色**。

### 3.11 背景高亮（层 11）

- 联动激活时，**仅替换背景层**：只覆盖背景层色块范围，不掩盖物件层物品；
- 位于**背景之上**、**方块高亮之下**；
- 颜色取联动配置所引用的**主题色**。

### 3.12 背景（层 12）

- **背景层**物品的图片，铺满整格（不内缩），作为方格底色；
- 位于**空方格之上**、**所有高亮层之下**。

### 3.13 空方格（层 13）

- 画布底色，是最底面的基础面；
- 任何图层都绘制在其之上；
- 不接收指针事件。

## 4. 叠加与遮挡规则

1. **同级不共存**：同一图层内的多个元素按创建顺序叠放，但本规范只约束**层与层**之间的次序。
2. **上层不透明即遮挡下层**：如方块高亮（层 10）为不透明色块，会完全遮住背景（层 12）与空方格
   （层 13），但不影响物体（层 4）与区域名称（层 3）。
3. **两框可同格叠加**：层 1 与层 2 允许落在同一格，此时表现为「外圈操作框 + 内圈鼠标框」。
4. **外边框不参与遮挡**：地图最外边框（层 5）绘制在画布矩形之外，与格内内容无重叠，
   其层级只用于与「边框 border」在角落处的交会取舍。
5. **指针事件与层级解耦**：层 1 / 层 2 及编辑器 affordance 一律不接收指针事件；
   可交互的只有画布容器本身、物体（选择类工具下）、区域名称。
6. **画布缩放不改变层序**：缩放由容器 `transform: scale()` 实现，不得为任何图层引入新的
   `z-index` 或层叠上下文。带 `z-index` 的包装元素会形成**层叠上下文**，从而压平其子层的次序，
   因此同一次渲染中**禁止**用带 `z-index` 的 wrapper 包裹多个不同层级的子层。

---

## 5. 变更流程

调整本规范时需要同时满足：

1. 更新 `MAP_LAYER_ORDER`（顺序即优先级）与 `MAP_LAYER_Z`（数值）；
2. 更新本文档的 §1 术语表、§2 次序与 z-index 表；
3. 更新图层顺序单元测试：`MAP_LAYER_ORDER` 项数、z-index 严格递减、以及各条相对关系断言；
4. 若新增图层，必须同步更新渲染代码中所有相关 `zIndex` 取值，禁止表外常量。

## 6. 验收清单

- [ ] `MAP_LAYER_ORDER` 共 13 项，顺序与 §2 完全一致；
- [ ] `MAP_LAYER_Z` 沿 `MAP_LAYER_ORDER` **严格递减**，且无重复值；
- [ ] 鼠标框 z-index > 操作框 z-index，二者同格可叠加且界限可辨；
- [ ] 区域名称不被物体、地图最外边框遮挡；
- [ ] 物体不被边框 border、地图最外边框、背景、区域边界线遮挡；
- [ ] 区域边界线不遮挡边框 border；
- [ ] 不可站立物体阴影位于区域边界线之下、区域高亮线之上；
- [ ] 区域高亮线不遮挡区域边界线，且严格水平 / 垂直；
- [ ] 方块高亮覆盖整格且不遮蔽区域名称与物体；
- [ ] 背景高亮不遮蔽物件层物品；
- [ ] 缩放画布不改变任何层序，不出现双重缩放。
