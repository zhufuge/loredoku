## 1. 修改详情

### MOD-701 触发效果：点击与触碰区分

**问题**
当前 `click` 与 `touch` 两种触发方式执行的是同一套渲染逻辑，用户无法感知差异。

**修改要求**

| 触发方式 | 触发源 | 效果行为 |
|---|---|---|
| **点击（click）** | 用户单击参与者（编辑器右侧抽屉中点击「预览点击效果」，或作品预览页点击左侧参与者项） | **持续性高亮**：目标对象高亮后**保持 3 秒**，期间再次点击可刷新；3 秒后淡出 |
| **触碰（touch）** | 鼠标进入参与者所在格、或移动端手指触碰（`touchstart`） | **瞬时高亮**：目标对象高亮 **1 秒** 后立即淡出，鼠标未离开时不重复触发 |

**渲染差异**

| 对象 | 点击（持续） | 触碰（瞬时） |
|---|---|---|
| 角色 | 描边 3px + `scale 1.08`，持续 3s | 描边 3px，持续 1s，无放大 |
| 物品 | 蒙层 `opacity 0.45`，持续 3s | 蒙层 `opacity 0.45`，持续 1s |
| 方格 | 背景层替换为参数色纯色块，持续 3s | 同左，持续 1s |
| 区域 | 区域内所有格背景层替换为参数色纯色块，持续 3s | 边框描线（见 MOD-709），持续 1s |

**约束**
- 同一参与者同时配置点击与触碰时，二者互不干扰；
- 点击持续高亮期间若触发触碰 → 触碰效果叠加渲染，1s 后消散，点击高亮继续；
- 高亮层位于网格线之下、悬停 / 选中效果之上（沿用 v0.3.1）。

**验收**
- 编辑器中预览点击效果 → 高亮持续 3 秒后消失；
- 预览触碰效果 → 高亮 1 秒后消失；
- 两种触发在同目标上视觉效果可区分（时长、放大、区域描线方式）。

### MOD-702 参与者「线索」字段

#### 2.1 字段定义

`characterSlots[i]` 元素新增字段：

| 字段 | 类型 | 约束 | 默认 | 说明 |
|---|---|---|---|---|
| `clue` | `string` | 长度 0~200 | 空字符串 | 参与者线索，一句话描述，支持部分词加粗 |

**结构示例**

```jsonc
{
  "characterId": 5,
  "themeColor": "#C08B4F",
  "clue": "他**喜欢**在**黄昏**时分来到**湖边**。",
  "triggers": [ /* ... */ ]
}
```

- 加粗语法：以 `**文本**` 表示加粗；
- 服务端仅做长度与合法性校验，不解析内容（渲染时由前端解析）。

#### 2.2 编辑入口

在参与者信息抽屉（右侧）中新增「线索」编辑区：

```
┌─ 参与者：村民A ──────────────────────────────┐
│ [头像]  名称：村民A  ♂                       │
│                                              │
│ 主题色：[色板 ▾]  ■ #C08B4F                  │
│                                              │
│ 线索：                                       │
│ ┌──────────────────────────────────────────┐ │
│ │ 他**喜欢**在**黄昏**时分来到**湖边**。    │ │
│ └──────────────────────────────────────────┘ │
│ 提示：用 **文字** 表示加粗                    │
│ 字数：23 / 200                                │
│                                              │
│ ── 触发效果 ──                               │
│ （…省略…）                                    │
└──────────────────────────────────────────────┘
```

- 使用多行 `Textarea`，实时统计字数；
- 提供加粗预览（编辑框下方预览渲染结果）；
- 超出 200 字禁止保存并提示。

#### 2.3 参与者框展示

参与者框（矩阵中的单元格）在头像**下方**增加一块**固定高度**的线索展示区：

```
┌──────────────┐
│              │
│   [头像]     │
│              │
├──────────────┤
│ 他喜欢在黄昏…│  ← 固定高度 40px（2 行）
│              │
└──────────────┘
```

**规则**
- 高度固定 40px（约 2 行文字），不随内容伸缩，保证矩阵行高一致；
- 无线索时该区**留空**（仍占 40px 高度，避免布局跳动）；
- 内容超出 2 行 → 尾部省略号；
- 加粗词按 `**...**` 解析为 `font-weight: 700`；
- 悬停参与者框时可展示完整线索的 Tooltip。

#### 2.4 移除「从参与者区移除」按钮

- 参与者信息抽屉底部**删除**「从参与者区移除」按钮；
- 移除参与者改为通过参与者框上的 `×` 触发（见 MOD-705）。

**验收**
- 编辑线索保存后，参与者框下方展示（加粗词正确渲染）；
- 无线索时框下方留出固定 40px 空白；
- 超出 2 行有省略号与 Tooltip；
- 抽屉中不再有「从参与者区移除」按钮。

### MOD-703 参与者头像主题色背景层

**问题**
主题色目前仅出现在头像描边，视觉表现力不足。

**修改要求**
- 头像外层增加**圆形背景色层**，半径比头像大 6px；
- 背景色填充 `themeColor`；
- 头像裁剪为圆形，居中叠放于背景层之上；
- 未设置主题色时背景色为 `#FFFFFF`，并加 1px 浅灰描边以在白色画布上可见。

**渲染结构**

```
┌──────────────┐
│   ╭──────╮   │  ← 背景层（半径 +6px，填充 themeColor）
│   │ 头像 │   │
│   ╰──────╯   │
└──────────────┘
```

**应用范围**
- 编辑器左侧参与者框；
- 编辑器右侧抽屉中的参与者头像；
- 作品预览页左侧参与者列表；
- 参与者信息编辑时主题色变更，背景层**实时预览**。

**验收**
- 修改主题色后，头像背景层立即跟随；
- 白色主题色在浅色背景下仍可辨识（有描边）。

### MOD-704 角色管理性别选择控件缩短

**问题**
角色管理页的性别选择控件（分段按钮组 / Select）在当前布局下被拉满整行，视觉上过长。

**修改要求**
- 控件宽度固定为 **140px**（或自适应内容 + 最小宽度 120px）；
- 不随表单项宽度拉伸（`align-self: flex-start` 或 `width: max-content`）；
- 分段按钮组两个选项各占 60px，总宽 120px + 内边距；
- 与标签「性别」同行展示，右侧不留大片空白。

**验收**
- 性别控件宽度约 120~140px，不再拉满整行；
- 与相邻表单控件对齐良好。

### MOD-705 参与者移除需二次确认

**问题**
点击参与者框上的 `×` 会立即移除，无确认步骤，用户易误操作。

**修改要求**
1. 点击 `×` → 弹出确认 `AlertDialog`：
   ```
   确定移除参与者「村民A」吗？
   该参与者及其线索与联动配置将一并移除。
   [取消] [移除]
   ```
2. 点击「移除」→ 执行移除 → **弹窗等待接口/状态响应后再关闭**（沿用 OPT-210 的 loading 规则）；
3. 点击「取消」→ 关闭弹窗，保留参与者；
4. 弹窗使用统一样式与 loading 按钮；
5. `Ctrl/Cmd + Z` 可恢复被移除的参与者。

**验收**
- 点击 `×` → 弹窗出现；
- 点「移除」→ 按钮进入 loading，完成后弹窗关闭，参与者消失；
- 点「取消」→ 参与者保留；
- 撤销可恢复。

### MOD-706 参与者区标题与物品栏头部对齐

**问题**
左侧参与者区的标题栏与底部物品栏（物品抽屉）头部在视觉上高度不一致，出现错位。

**修改要求**
- 统一两者标题栏高度为 **36px**；
- 内边距统一为 `padding: 0 12px`；
- 字号、字重、行高统一：
  - 字号：13px；
  - 字重：600；
  - 行高：36px；
  - 颜色：`#1F2937`；
- 两者顶部对齐（同一水平基线）。

**验收**
- 参与者区标题栏与物品栏头部视觉高度一致；
- 文字基线对齐。

### MOD-707 参与者框放大、间距加大

**问题**
当前参与者框偏小、间距偏密，视觉压迫。

**修改要求**

| 项 | 原值 | 新值 |
|---|---|---|
| 单元格最小边长 | 36px | **56px** |
| 单元格理想边长 | 自适应 | 自适应但**不小于 56px** |
| 单元格间距（gap） | 6px | **10px** |
| 头像是内边距 | 4px | **6px** |
| 线索区高度 | — | 40px（MOD-702） |

- 当面板宽度不足以容纳 `cols × 56 + (cols-1) × 10` 时：
  - 优先减小列数（`cols - 1`）重新计算；
  - 若 `cols = 1` 仍不足 → 面板允许纵向滚动；
- 矩阵整体宽度对齐到面板宽度，居中。

**验收**
- 参与者框明显大于 v0.3.1；
- 框间距加大后不显拥挤；
- 面板不出现横向溢出。

### MOD-708 联动对象批量添加

#### 8.1 物品批量选择

**问题**
添加物品联动时只能一个个加，效率低。

**修改要求**
- 点击「+ 添加对象」→ 选择「物品」→ 弹出**多选列表**：
  - 按**同类物品**（相同 `itemId`）聚合展示，如「篝火 × 5」；
  - 勾选一个 `itemId` 相当于对**地图上所有该类型物品**一次性添加；
  - 也支持展开后单独勾选具体实例（按锚点格定位），逐格选择；
  - 列表顶部提供「全选 / 全不选」；
  - 选中数量实时显示：「已选 3 类 / 共 12 个实例」。

- 添加后，触发效果中每条记录**按 `itemId` 聚合存储**（避免数据膨胀）：
  ```jsonc
  { "type": "item", "id": 12, "scope": "all", "effect": "highlight", "color": "red" }
  ```
  - `scope: 'all'` 表示该类型所有实例；
  - 若用户展开后只选部分实例，则 `scope: 'instances'`，并附实例坐标列表：
    ```jsonc
    { "type": "item", "id": 12, "scope": "instances",
      "instances": [[1,2],[3,4]], "effect": "highlight", "color": "red" }
    ```

#### 8.2 方格批量选择（矩阵选择器）

**问题**
添加方格联动时需手动输入坐标或单格点击。

**修改要求**
- 点击「+ 添加对象」→ 选择「方格」→ 弹出**矩阵选择器**：

  ```
  ┌─ 选择方格 ────────────────────────────┐
  │ 快捷： [ 整行 ▾ ] [ 整列 ▾ ]           │
  │        或 [ 矩形范围 ▾ ]                │
  │                                        │
  │    C1  C2  C3  C4  C5  C6              │
  │  R1 □  □  □  □  □  □                  │
  │  R2 □  ■  ■  □  □  □                  │
  │  R3 □  ■  ■  □  □  □                  │
  │  R4 □  □  □  □  □  □                  │
  │  R5 □  □  □  □  □  □                  │
  │  R6 □  □  □  □  □  □                  │
  │                                        │
  │ 已选 4 格                              │
  │ [清空] [全选]       [取消] [确定]      │
  └────────────────────────────────────────┘
  ```

- **自由点击**：在矩阵中点击格子切换选中状态；
- **快捷选择**：
  - 「整行」：下拉选择 `R1..Rn` → 该行整行选中；
  - 「整列」：下拉选择 `C1..Cn` → 该列整列选中；
  - 「矩形范围」：输入 `R起点~R终点, C起点~C终点` → 矩形范围选中；
- 快捷操作**追加**到当前选中集合（不清空），支持组合；
- 矩阵尺寸与当前地图 `gridSize` 一致；
- 已有选择来自其它类型不影响本弹窗初始状态（本弹窗从零开始）。

- 保存时方格联动记录为**坐标集合**：
  ```jsonc
  { "type": "cell", "cells": [[2,2],[3,2],[2,3],[3,3]], "effect": "highlight", "color": "red" }
  ```
  > 数据结构由 v0.3.1 的单格 `{x, y}` 改为数组 `cells`。

#### 8.3 数据迁移

v0.3.1 中已存在的方格联动记录 `{ type: 'cell', x, y, ... }` → 迁移为 `{ type: 'cell', cells: [[x, y]], ... }`。

物品联动记录 `{ type: 'item', id, ... }` → 补 `scope: 'all'`。

#### 8.4 渲染兼容

- `scope: 'all'` → 高亮地图上所有该 `itemId` 的实例；
- `scope: 'instances'` → 仅高亮 `instances` 中列出的坐标；
- `type: 'cell'` 的 `cells` 数组 → 逐格高亮。

**验收**
- 添加物品联动 → 可多选聚合，一次提交多个；
- 添加方格联动 → 矩阵弹窗支持自由点击、整行 / 整列 / 矩形快捷；
- 保存后配置持久化，渲染效果覆盖所有选中目标；
- 旧数据自动迁移。

### MOD-709 区域触碰效果改为沿边框描蓝线

**问题**
v0.3.1 中区域触碰效果为「区域内所有格背景层替换为参数色纯色块」，与方格效果重复，无法区分。

**修改要求**
- 区域**触碰**效果改为：沿区域**边框**绘制一条 **2px 蓝色**（`#3B82F6`）描线；
- 描线**位于原区域边框内侧**，不覆盖原边框；
- 持续 1 秒后淡出；
- **区域点击效果**保持 v0.3.1：区域内所有格背景层替换为参数色纯色块，持续 3 秒。

**渲染结构**

```
原区域边框（参数色，粗线）
 ┌────────────┐
 │╭──────────╮│  ← 蓝色内描线（2px，触碰时出现）
 ││          ││
 │╰──────────╯│
 └────────────┘
```

- 蓝色固定为 `#3B82F6`，不随 `color` 参数变化（红 / 蓝选择对区域触碰无效，但仍保留在数据结构中，供未来扩展）；
- 若区域形状非矩形，描线沿实际边界绘制（复用区域边框的线段生成算法，仅内缩 2px）。

**验收**
- 触碰区域 → 区域边框内侧出现蓝色描线，1 秒后消失；
- 点击区域 → 区域内所有格背景层变为参数色纯色块，持续 3 秒；
- 两种效果不相互覆盖。

### MOD-710 主题色限制移除

**修改要求**

1. **删除文案**
   - 移除所有位置的「蓝色为高亮专用色，不可作为主题色」提示；
   - 移除自定义 HEX 输入时对蓝色系的拦截逻辑。

2. **色板调整**
   - 提供的预设色板**排除高亮度颜色**（纯白、亮黄、亮青、荧光色等），以保证参与者框在浅色背景上的可读性；
   - 保留以下建议色板：
     ```
     #FFFFFF（默认白，保留但需描边）
     #000000  深黑
     #6B7280  灰
     #8B4513  棕
     #C08B4F  浅棕 / 驼色
     #DC2626  深红
     #EA580C  橙
     #CA8A04  深黄 / 芥末
     #16A34A  深绿
     #0D9488  墨绿 / 青绿
     #7C3AED  深紫
     #DB2777  深粉
     #BE185D  玫红
     #1E40AF  深蓝（允许，仅作主题色）
     #0F766E  深青
     ```
   - 移除：纯白以外的所有高亮度色（`#00FFFF`、`#FFFF00`、`#00FF00`、`#FF00FF` 等）。

3. **自定义输入**
   - 用户可在 HEX 输入框中输入任意合法 `#RRGGBB`；
   - 前端对**极高亮度**（HSL 的 `L > 85%`）给出**非阻断式提示**「该颜色较亮，可能影响可读性」，但**允许保存**；
   - 不再校验是否为蓝色系。

4. **默认值**
   - 未选择时 `themeColor = '#FFFFFF'`；
   - 头像背景层为白色时自动加 1px 浅灰描边（MOD-703）。

**验收**
- 色板中不再出现纯白以外的亮色（如荧光黄、亮青）；
- 可选择蓝色作为主题色；
- 选择高亮度的自定义色仅提示不阻断；
- 不再出现「蓝色为高亮专用色」文案。
