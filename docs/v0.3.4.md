## 1. 地图方格展示

### 1.1 图层优先级（由上至下）

方格在渲染时，元素严格按以下顺序堆叠，**序号越小越靠上**：

| 序号 | 图层名 | 说明 |
|---|---|---|
| 1 | 当前方格辅助提示框 | 当前操作或选择方格的提示 |
| 2 | 区域名称 | 区域名称标签 |
| 3 | 物体 | 物件层 / 背景层的物品图 |
| 4 | 边框（Border） | 网格线（内部分隔线 + 画布外边框） |
| 5 | 区域边界线 | 围绕区域外轮廓的描边 |
| 6 | 不可站立物体阴影 | 不可站立物品所在格的灰度蒙版 |
| 7 | 区域高亮线 | 区域被激活时的内描边 |
| 8 | 方块高亮 | 与角色联动时的纯色块 |
| 9 | 背景高亮 | 与角色联动时的背景纯色块 |
| 10 | 背景 | 背景层物品 |
| 11 | 空方格 | 空白底 |

> 说明：
> - 「区域边界线」位于 Border 之下，是因为 Border（网格线）需要清晰可见，避免被区域边界遮挡；
> - 「物体」位于 Border 之上，保证物品不被网格线切割视觉；
> - 物品图本身遵守「严格裁剪在格子内、不覆盖网格线」的约束（沿用 v0.2.4 OPT-205），因此列表位置与实际视觉不冲突。

### 1.2 各图层展示方式

#### 1.2.1 当前方格辅助提示框

- **结构**：`InnerLine（内描边）+ 阴影`
- **内描边**：紧贴 Border 内侧，1px，颜色随状态变化（见 §2.1）
- **阴影**：与 Border 重合，叠加在 Border 上，为**灰度半透明**（`rgba(0,0,0,0.15)`），不改变 Border 位置
- **用途**：表示当前操作或选择的方格

#### 1.2.2 区域名称

- 字体：白色（`#FFFFFF`）
- 字体描边：**在 v0.3.3 基础上再加粗一点**（`-webkit-text-stroke` 由 3px 调整为 **4px**，或同等视觉效果）
- 位置：沿用 v0.2.4 OPT-303：紧贴区域最下方格行底边，居中
- 无背景、无圆角（沿用）

#### 1.2.3 物体

- 保持当前展示方式（v0.2.4 OPT-205：严格裁剪在格内、不覆盖网格线）

#### 1.2.4 区域边界线

- 围绕区域内方格的**外轮廓**描边（非内部单元格分界）；
- **线宽比 Border 更宽**：
  - Border（网格线）为 2px；
  - 区域边界线为 **参数色 + 4~12px 可调**（默认 6px，沿用 v0.2.5 OPT-401）；
- **两个区域的边界线可以重合展示**：
  - 相邻区域各自绘制边界线，交界处两条线同时渲染；
  - 不做合并、不做优先级覆盖；
  - 视觉上交界处可能变粗，属预期行为。

#### 1.2.5 不可站立物体阴影

- 若该格物件层物品 `can_stand === false`，在该格 Border 内侧叠加一层**超低透明度灰度蒙版**：
  - 颜色：`rgba(0,0,0,0.08)`；
  - 覆盖范围：Border 内侧整格；
  - 不遮挡物体图（蒙版在物体图之上、Border 之下）；
- 用途：直观提示玩家此格不可站立。

#### 1.2.6 区域高亮线

- 区域被激活（当前操作所在区域）时，沿**区域边界线内侧**绘制一圈 `InnerLine`；
- 线宽 2px；
- 颜色：**蓝色 `#3B82F6`**（联动与鼠标悬停均使用蓝色）；
- 未激活时不渲染。

#### 1.2.7 方块高亮

- 与角色联动时的效果；
- 在 Border 内侧**使用纯色块完全覆盖背景**（不透明）；
- 颜色：红 / 蓝（联动参数）；
- 用途：角色联动时对方格的整块染色。

#### 1.2.8 背景高亮

- 与角色联动时的效果；
- 在 Border 内侧覆盖背景层物品的颜色块；
- 颜色：红 / 蓝（联动参数）；
- 与方块高亮的区别：**背景高亮仅替换背景层**，保留物件层物品可见；方块高亮覆盖整格背景（物件层也被覆盖）。

#### 1.2.9 背景

- 背景层物品（如草地、水面），渲染在 Border 内侧；
- 若该格无背景层物品，则不渲染。

#### 1.2.10 空方格

- 无任何物品的格子；
- 展示网格底色（当前为默认底色，可为白色或浅灰，沿用现有实现）。

## 2. 地图方格与鼠标的交互

### 2.1 方格（Hover）

- **触发**：鼠标进入方格（`pointerenter`）；
- **表现**：
  - 该方格上出现**当前方格辅助提示框**（见 1.2.1）；
  - **颜色**：
    - 方格内**无不可站立物品** → 辅助提示框为**白色**；
    - 方格内**有不可站立物品** → 辅助提示框为**中等红色**（`#E57373` 或同色系）；
  - 阴影（灰度蒙版）**保持不变**（不因悬停而增减）；
  - 优先级**最高**（在最上层，覆盖所有其他元素）；
- **结束**：鼠标移出方格，提示框消失。

### 2.2 区域（Hover）

- **触发**：鼠标进入**某一区域**覆盖的任意方格；
- **表现**：
  - 该区域的**区域名称**：
    - 字体描边颜色改为**蓝色 `#3B82F6`**；
    - **字体放大**（如从 14px 放大到 16px）；
  - 该区域的**区域高亮线**出现（蓝色 `#3B82F6`，2px InnerLine）；
  - 区域内其他元素（物体、Border 等）不变；
- **结束**：鼠标移出该区域覆盖的所有方格，恢复原状。

**边界情形**
- 若鼠标从区域 A 的格子直接进入区域 B 的格子：A 恢复原状，B 高亮；
- 若鼠标进入的区域无名称（未命名）：仅显示区域高亮线，无名称变化。

### 2.3 物品（Hover）

- **触发**：鼠标进入**带有物体的方格**；
- **表现**：
  - 该物体的图片**向上拉伸一点点**（推荐值：向上延伸 `4px`，或高度放大 5%，具体实现可调）；
  - 效果平滑（`transition: transform 120ms ease-out`）；
- **结束**：鼠标移出该格，图片恢复原位。

### 2.4 多效果叠加

- 鼠标悬停某格时，**方格提示框、区域高亮、物品拉伸**可同时出现；
- 叠加顺序遵循 §1.1 的图层优先级；
- 三者互不覆盖：
  - 方格提示框在最上层；
  - 区域名称在方格提示框之上但视觉上位于区域下方格行（不冲突）；
  - 物品拉伸仅影响图片自身。

**示例场景**
- 鼠标悬停在某区域的格子上，且该格有物品：
  - 方格提示框出现（白色或红色）；
  - 区域名称变蓝放大、区域高亮线出现；
  - 物品图片向上拉伸；
  - 三种效果同时可见。

## 3. 地图方格与角色联动的交互

联动效果由参与者框的悬停 / 点击触发（沿用 v0.3.3 MOD-802），作用在地图方格上的表现如下：

| 联动对象 | 效果 | 表现 |
|---|---|---|
| **方格** | 方块高亮 | Border 内侧整格覆盖纯色块（红 / 蓝），物件层与背景层均被覆盖 |
| **区域** | 区域高亮 | 区域名称字体描边变蓝 + 放大；区域高亮线出现（蓝色 2px InnerLine） |
| **物体** | **方块高亮**（非物体高亮） | 该物体所在的格（或该物体覆盖的所有格）使用方块高亮；**不再使用半透明蒙层** |
| **背景** | 背景高亮 | 仅替换背景层物品为参数色块；物件层物品保持可见 |

> **重要变更**：
> - v0.3.3 中「物品联动 = 半透明蒙层」调整为**方块高亮**；
> - 物件层物品所在的格，联动时整格覆盖纯色块；
> - 若该物品是多格物品，覆盖其全部占位格。

**区域联动的呈现**
- 无持续时间限制（沿用 v0.3.3：悬停移出即结束；点击为开关式）；
- 区域内所有方格共享同一个高亮线（非逐格描边）；
- 同时只能有一个区域处于激活状态（沿用单例约束）。

## 4. 地图方格校验

### 4.1 不可站立物品的放置校验

| 项 | 规则 |
|---|---|
| 不可站立物品可放置于**物件层** | ✅ 允许 |
| 不可站立物品可放置于**背景层** | ❌ 不允许（背景层仅接受 `category === 'background'` 的物品） |
| 不可站立物品所在的格子 | 不可站角色（若有"角色可进入地图"的场景，需另行澄清；当前 v0.3.1 已取消角色进入地图） |

**校验执行**
- 前端在拖入物品时校验物品 `category` 与目标图层是否匹配；
- 服务端在保存 `draft_data` 时按 zod schema 校验；
- 若用户在物品管理中把 `can_stand` 从 `true` 改为 `false`，已放置的格子**不自动移除**，仅更新"不可站立阴影"的展示。

### 4.2 其他校验

- 保留 v0.3.1 §3.3 发布的 P1~P5 规则；
- 保留 v0.3.2 §8.2 方格联动的 `cells` 坐标必须在 `[0, gridSize)` 内。

## 5. 作品管理

### 5.1 变更

| 项 | v0.3.3 | v0.3.4 |
|---|---|---|
| 页面入口 | 顶部导航「作品」 | 不变 |
| 地图切换入口 | 右上角地图下拉 | **移除** |
| 作品展示 | 按选中地图分组展示 | **所有作品平铺在表格中** |

### 5.2 表格列

| 列 | 说明 |
|---|---|
| 作品编号 | 版本号（如 `v3`） |
| 地图名称 | 该作品所属地图的名称 |
| 发布时间 | 格式：`YYYY-MM-DD HH:mm` |
| 尺寸 | `n × n` |
| 参与者数 | 该作品的参与者数量 |
| 区域数 | 该作品的区域数量 |
| 物品数 | 该作品放置的物品实例总数 |
| 备注 | 发布时的备注 |
| 操作 | 查看效果 / 导出 / 基于此作品创建草稿 / 删除 |

### 5.3 排序与筛选

- **默认排序**：按发布时间倒序（最新在前）；
- **筛选**：
  - 按地图筛选（下拉多选）；
  - 按时间范围筛选（可选）；
  - 关键词搜索（作品编号 / 备注 / 地图名）；
- **分页**：每页 20 条，支持切换每页条数。

### 5.4 操作行为

| 操作 | 行为 |
|---|---|
| 查看效果 | 跳转 `/works/:workId/view` |
| 导出 | 下载该作品 JSON 快照 |
| 基于此作品创建草稿 | 调用 `POST /api/projects/:id/versions/:versionNo/draft`，成功后跳转编辑器 |
| 删除 | 二次确认弹窗，等待响应后再关闭（沿用 OPT-210） |

### 5.5 空状态

- 无作品时展示：「暂无作品，发布一个试试」；
- 筛选后无结果时展示：「没有符合条件的作品」。
