## 1. Bug 修复

### BUG-401 选择状态下格子内图片无法被选中

**现象**：选择工具下点击画布上的物品图片，无任何反应，右侧不展示信息。

**根因**：v0.2.4 修复 FIX-301 时把物品层 / 角色层 `pointer-events` 一并设为 `none`，导致点击命中也失效。

**修复要求**
1. 选择工具下物品层、角色层 `pointer-events` 恢复为 `auto`，仅保留 `onClick` 选中，不注册任何拖动逻辑。
2. 点击物品 → `selection = { type: 'cell', x, y }`（命中角色则为 `type: 'character'`）。
3. 悬停光标 `pointer`，禁止 `grab` / `move`；悬停格子显示 `ring-2 ring-blue-500`。
4. 多格物品点击其占位范围内任意格都命中该物品，以锚点格作为选中坐标。
5. 确认 v0.2.4 的 FIX-301（拖动无反应）仍成立。

**验收**
- 点击物品图片 → 右侧展示信息；
- 按住物品拖动 → 无任何位移；
- 多格物品任一覆盖格可命中。

### BUG-402 槽位上角色的 × 无法删除

**现象**：悬停槽位角色出现 ×，点击后角色不消失、槽位不清空、无提示。

**根因（任一或组合）**
1. × 的 `onClick` 未绑定处理函数；
2. × 点击冒泡到槽位被拖拽启动逻辑吞掉；
3. `clearCharacterSlot` 未实现或未返回新数组；
4. × 被覆盖层遮挡或 `pointer-events: none`。

**修复要求**
1. × 按钮监听 `onPointerDown` 并 `stopPropagation()`，`onClick` 调用 `clearCharacterSlot(slotIndex)`。
2. Action 语义：仅从 `characterSlots` 中移除该角色（不涉及地图数据），返回新数组，`dirty = true`，入撤销栈。
3. 交互细节：
   - × 尺寸 ≥ `16×16`，`cursor: pointer`；
   - 悬停槽位时显示 ×，移出隐藏；× 自身悬停不隐藏；
   - 点击 × 不触发槽位选中，也不触发拖拽。
4. 槽位拖拽启动逻辑在 `pointerdown` 时检查 `event.target` 命中 × 时直接跳过。
5. `Ctrl/Cmd + Z` 可恢复角色到原槽位。

**验收**
- 点击 × → 角色立即消失；
- 撤销 → 回到原槽位；
- 快速连点仅执行一次。

### BUG-403 槽位角色无法拖到地图

**现象**：从槽位拖拽角色到画布，松手后角色不落位，槽位也不清空。

**根因（任一或组合）**
1. `pointerup` 未在正确元素上触发（未 `setPointerCapture`）；
2. 坐标换算错误，落位判定失败；
3. 落位校验失败但无提示；
4. `placeCharacter` action 未原子更新两个数组；
5. 拖拽启动被 BUG-402 修复过程误删。

**修复要求**

**拖拽生命周期**
- `pointerdown` → `setPointerCapture` → 记录 `{ characterId, sourceSlotIndex }`；
- `pointermove` → 更新幽灵预览 + 合法/非法落位高亮；
- `pointerup` → 释放 capture → 执行落位校验；
- `pointercancel` / `Esc` → 取消，角色留槽位。

**落位校验**

| 检查 | 失败提示 |
|---|---|
| 目标格在画布内 | 「请拖入画布区域」 |
| 目标格无其他角色 | 「该格已有角色」 |
| 目标格物件层为空或 `can_stand === true` | 「该格不可站角色」 |

**落位成功**
1. `characterSlots[slotIndex] = null`；
2. `placedCharacters.push({ characterId, x, y, originSlotIndex })`；
3. `dirty = true` 并入撤销栈；
4. Toast「已放置角色」。

**视觉反馈**
- 幽灵预览跟随光标，半透明；
- 合法格 `ring-2 ring-green-500`；非法格 `ring-2 ring-red-500`；
- 光标 `grabbing`。

**唯一入口**：仅通过拖拽；单击槽位仅选中（保持 FIX-303）。

**验收**
- 拖到可站立格 → 成功落位，槽位清空；
- 拖到不可站立格 / 已有角色格 / 画布外 → 拒绝并提示；
- 拖拽中按 Esc → 取消；
- 落位后撤销 → 回到原槽位。

### BUG-404 标尺残留背景与边框

**现象**：v0.2.4 要求去掉标尺背景，实际仍见浅灰背景或边框线。

**修复要求**
1. 标尺容器 `background: transparent`，移除所有 `bg-*` 类。
2. 移除底部（顶部标尺）/ 右侧（左侧标尺）边框及左上角交叉区填充。
3. 文本样式：

   | 项 | 原值 | 新值 |
   |---|---|---|
   | 字号 | 11px | 13px |
   | 字重 | 400 | 600 |
   | 颜色 | `#374151` | `#1F2937` |

4. 行列高亮改用**文字色变化 + 2px 下划线**（如 `#2563EB`），不使用整块背景。
5. 保持 v0.2.4 OPT-218：标尺贴边对齐地图方格。

**验收**
- 标尺无背景、无边框；
- 文字 13px 加粗清晰；
- 悬停行列文字高亮，无背景块。

### BUG-405 格子内容仍可被拖动

**现象**：选择工具下按住画布物品 / 角色拖动，出现位移或幽灵预览。

**根因**：BUG-401 打开 `pointer-events` 后，旧的拖动处理未彻底删除。

**修复要求**
1. 画布内物品层、角色层**不得**注册 `pointermove` / `pointerup` 拖动处理，`onPointerDown` 不设 `pointercapture`。
2. 悬停光标为 `pointer`，禁止 `grab` / `grabbing` / `move`。
3. 全项目仅保留两类拖拽：
   - 从物品抽屉拖物品到画布；
   - 从角色槽位拖角色到画布。
4. 代码审查：
   - `CellItem` / `PlacedCharacter` 无拖动处理；
   - 全局 grep `dragging` / `dragStart` / `ghost`，确认仅剩上述两类。
5. 保留：点击选中、键盘移动（若已支持）、`Delete` 删除。

**验收**
- 按住物品 / 角色拖动无任何位移；
- 光标为 pointer；
- 物品抽屉与角色槽位的拖拽正常。

### BUG-406 橡皮擦未按「先物件后背景」顺序清除

**现象**：某格同时有背景层与物件层物品，橡皮擦点击时立即清除背景，物件仍在。

**修复要求**

**清除顺序**：物件层 → 背景层（视觉上层到下层）。

**单次点击**

| 当前格状态 | 结果 |
|---|---|
| 物件 + 背景 | 仅清除物件 |
| 仅物件 | 清除物件 |
| 仅背景 | 清除背景 |
| 空 | 无操作 |

**拖拽擦除**
- 按住拖过时每进入新格，按上述顺序**最多清除一层**；
- 同一格不重复处理（记录已处理集合）。

**与 `activeLayer` 关系**
- 橡皮擦忽略 `activeLayer`，严格按「物件 → 背景」顺序；
- 后续可扩展 `Alt + 点击` 限定当前图层（本版不实现）。

**撤销**
- 每次清除为独立可撤销操作；
- 连续两次清除 → 两条历史记录，撤销按逆序恢复。

**验收**
- 双层格第一次点击清物件，第二次清背景；
- 拖拽连续擦除每格至多清一层；
- 撤销按逆序恢复。

## 2. 优化

### OPT-401 区域默认边框宽度改为 6px

| 项 | 原值 | 新值 |
|---|---|---|
| 默认 `borderWidth` | 4px | 6px |
| 取值范围 | 4~12px | 不变 |

**同步位置**
- 新建区域弹窗 Slider 默认 6；
- 地图 JSON `regions[].borderWidth` 新建默认写 6；
- 已有区域不改写。

**验收**：新建区域边框明显更粗，Slider 可覆盖。

---

### OPT-402 停用标签去掉「缺图片」后缀

- 停用标签文案由「未启用（缺图片）」改为 **「未启用」**。
- 范围：物品列表、角色列表、编辑器兜底文案。
- 删除图片时的弹窗提示保持「删除图片后，该物品将自动停用」，不改措辞。

**验收**：停用标签仅为「未启用」，无括号后缀。
