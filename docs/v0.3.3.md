### MOD-801 参与者信息编辑面板重构

#### 1.1.1 主题色

1. **新增一个色**

### MOD-802 联动效果预览移至参与者槽位

#### 1.2.1 移除抽屉内的预览按钮

- 右侧参与者信息抽屉中不再提供「预览点击效果 / 预览触碰效果」按钮。

#### 1.2.2 预览入口与触发时机

预览入口为**左侧参与者矩阵**中的每个参与者框，通过两种手势触发：

| 手势 | 触发时机 | 结束时机 |
|---|---|---|
| **触碰** | 鼠标**移入**参与者框（`pointerenter`） | 鼠标**移出**参与者框（`pointerleave`）时立即结束 |
| **点击** | 鼠标**单击**参与者框 | **再次单击**该参与者框时结束（开关式） |

#### 1.2.3 高亮时长

- **不限制时间**：高亮持续存在，直到上述结束条件被满足；
- 不再有「持续 1 秒 / 3 秒后自动淡出」的逻辑。

#### 1.2.4 单例约束：同一时间只能触发一个

- 全局维护一个 `activeParticipantId`，同一时刻只允许一个参与者的联动处于激活状态；
- 触发新的参与者时，**自动结束**当前已激活的参与者联动；
- 结束方式：立刻移除高亮层，150ms 淡出过渡。

**状态机**

```
[无激活] --点击 P1--> [激活 P1]
[激活 P1] --再次点击 P1--> [无激活]
[激活 P1] --点击 P2--> [激活 P2]（P1 自动结束）
[激活 P1] --移入 P2--> [激活 P2]（P1 自动结束）
[无激活] --移入 P1--> [激活 P1]
[激活 P1] --移出 P1--> [无激活]
```

**边界规则**
- 点击 P1 激活后，鼠标移出 P1 → **不结束**（点击是开关式）；
- 鼠标再移入 P1 → **不改变状态**（已是点击激活，`pointerenter` 不再覆盖）；
- 鼠标移入 P2 → 结束 P1，激活 P2；
- 鼠标移出 P2 → 若 P2 是通过悬停触发的，立即结束；若 P2 是通过点击触发的，保持激活；
- 点击 P2（P2 已通过悬停激活）→ 切换为点击式激活（保持激活，不结束）；
- 按 `Esc` → 强制结束当前激活。

**实现要点**
- `activeParticipantId: number | null` 存于编辑器 Store；
- `activationMode: 'hover' | 'click' | null` 记录激活方式；
- `pointerenter`：若 `activationMode === 'click'` 且目标为当前参与者 → 忽略；否则设置 `activeParticipantId = target`、`activationMode = 'hover'`；
- `pointerleave`：仅当 `activationMode === 'hover'` 且目标为当前参与者 → 清空；
- `click`：若当前已是该参与者且 `activationMode === 'click'` → 清空；否则设置 `activeParticipantId = target`、`activationMode = 'click'`。

#### 1.2.5 渲染规则

| 对象 | 效果 | 渲染 |
|---|---|---|
| 角色 | 高亮角色 | 头像外圈以参数色（红 / 蓝）描边 3px + 轻微放大 `scale 1.08` |
| 物品 | 高亮物品 | 物品图外覆盖半透明参数色蒙层（`opacity 0.45`） |
| 方格 | 高亮方格 | 该格背景层临时替换为参数色纯色块 |
| **区域** | **高亮区域** | **沿区域边框内侧绘制 2px 蓝色描线（`#3B82F6`）**，点击与触碰效果一致 |

**区域高亮说明**
- 不再区分点击 / 触碰的区域渲染差异；
- 统一为「区域内边缘蓝色描线」；
- 描线位于原区域边框内侧，不覆盖原边框；
- 非矩形区域沿实际边界绘制（复用区域边框线段生成算法，整体内缩 2px）；
- 蓝色固定 `#3B82F6`，不随联动的红 / 蓝参数变化。

**渲染层级**

```
网格底色 → 背景层物品 → 区域填充 → 物件层物品 → 区域边框
→ 高亮层（角色 / 物品 / 方格 / 区域） → 网格线 → 悬停 / 选中效果 → 区域名称标签
```

#### 1.2.6 点击与信息抽屉的协同

- 单击参与者框：
  - 触发联动高亮（开关式激活）；
  - 同时在右侧抽屉展示该参与者信息（用于编辑）；
- 悬停进入参与者框：
  - 仅触发联动高亮（悬停式激活）；
  - 不切换抽屉内容。

**验收**

| 场景 | 期望 |
|---|---|
| 鼠标移入参与者框 A | A 的联动高亮出现 |
| 鼠标移出 A | A 的联动高亮消失 |
| 点击参与者框 A | A 的联动高亮出现且持续 |
| 点击 A 后移出再移入 | 高亮保持（点击式，不受移入移出影响） |
| 再次点击 A | A 的联动高亮消失 |
| A 点击激活中，点击 B | A 立即消失，B 出现 |
| A 悬停激活中，移入 B | A 立即消失，B 出现 |
| A 悬停激活中，移出 A | A 消失 |
| 按 `Esc` | 当前激活的联动消失 |
| 点击参与者框 | 右侧抽屉同步展示该参与者信息 |
| 悬停参与者框 | 右侧抽屉不切换 |
| 触发区域联动 | 区域边框内侧出现 2px 蓝色描线，不限时长，随激活状态出现 / 消失 |

### MOD-803 参与者槽位框进一步放大

**问题**
v0.3.2 中参与者框虽有 56px 最小边长，但线索文本仍展示不全。

**修改要求**

| 项 | v0.3.2 | v0.3.3 |
|---|---|---|
| 单元格最小边长 | 56px | **72px** |
| 单元格间距（gap） | 10px | **12px** |
| 头像是内边距 | 6px | **8px** |
| 线索区高度 | 40px | **56px（3 行）** |
| 头像尺寸 | 自适应 | 最小 48×48 |

**线索区文本**
- 允许展示 **3 行**文字；
- 字号 11px，行高 16px；
- 超出 3 行 → 尾部省略号；
- 无线索时保留 56px 空白。

**布局自适应**
- 面板宽度不足容纳 `cols × 72 + (cols-1) × 12` 时：
  - 优先减小列数重新计算（保持矩阵布局的目标宽高比）；
  - `cols = 1` 时仍不足 → 面板纵向滚动；
- 最后一行不满时居中排列。

**验收**
- 参与者框明显大于 v0.3.2；
- 线索文本可完整展示 3 行内内容；
- 面板不横向溢出；
- 缩放到较小 n 值时，矩阵仍保持合理比例。
