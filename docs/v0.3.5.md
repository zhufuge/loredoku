## 1. 画布自适应

### 1.1 自适应规则

画布地图整体**默认大小自适应**编辑器可用区域（去除左侧参与者区、右侧信息抽屉、顶部标尺、底部工具条后的剩余空间）。

**方格宽度约束**

| 项 | 值 |
|---|---|
| 最小宽度 | 90px |
| 最大宽度 | 240px |
| 理想宽度 | 自适应计算 |

**计算公式**

```
availableW = 编辑器可用宽度 - 左右内边距
availableH = 编辑器可用高度 - 上下内边距

cellByW = (availableW - (gridSize-1) * borderGap) / gridSize
cellByH = (availableH - (gridSize-1) * borderGap) / gridSize

idealCell = min(cellByW, cellByH)
finalCell = clamp(idealCell, 90, 240)
```

- 若 `idealCell < 90` → 取 90（画布可能出现滚动条）；
- 若 `idealCell > 240` → 取 240（画布居中留白，不再拉伸）；
- `borderGap` 为相邻格共享线宽（2px），实际计算可忽略。

### 1.2 生效时机

- 进入编辑器时按上述规则计算初始 `cellSize`；
- 窗口 `resize` 时，若用户**未手动缩放 / 拖拽过画布**，则重新自适应；
- 用户手动缩放（`Ctrl + 滚轮`）后，本次会话不再自动重算，直到点击「重置视图」（`Ctrl + 0`）。

### 1.3 与缩放倍率的关系

- `cellSize` 为基准值（100% 缩放下的像素宽度）；
- 实际渲染宽度 = `cellSize × zoom`；
- 缩放倍率范围保持 25% ~ 400%。

**验收**
- 进入编辑器，画布自动铺满可用区域，方格宽度在 [90, 240] 之间；
- 不同 `n` 值下均自适应（如 `n = 2` 时方格接近 240，`n = 24` 时方格接近 90）；
- 窗口变化后自动重算（未手动缩放前提下）。

## 2. 参与者框加大

| 项 | v0.3.3 | v0.3.5 |
|---|---|---|
| 单元格最小宽度 | 72px | **88px** |
| 单元格最小高度 | 72px | **104px** |
| 头像尺寸 | ≥ 48×48 | **≥ 56×56** |
| 线索区高度 | 56px（3 行） | **72px（3 行）** |
| 单元格间距（gap） | 12px | **14px** |

**线索区**
- 行高由 16px 调整为 **20px**；
- 字号保持 11px，允许展示 3 行；
- 超出 3 行省略号 + Tooltip。

**布局**
- 面板宽度不足时，优先减少列数（保持矩阵比例），`cols = 1` 仍不足时纵向滚动。

**验收**
- 参与者框明显大于 v0.3.3；
- 头像与线索文本展示更从容；
- 不同 `n` 下矩阵比例合理，无横向溢出。

## 3. 方格展示

### 3.1 不可站立物体阴影加深

| 项 | v0.3.4 | v0.3.5 |
|---|---|---|
| 蒙版颜色 | `rgba(0,0,0,0.08)` | **`rgba(0,0,0,0.18)`** |
| 覆盖范围 | Border 内侧整格 | 不变 |

- 蒙版位于物体图之上、Border 之下（图层位置不变）；
- 加深后不可站立状态更易辨识。

### 3.2 方格线条定义（明确）

#### 3.2.1 网格

```
┌────┬────┬────┬────┐
│    │    │    │    │
├────┼────┼────┼────┤
│    │    │    │    │
├────┼────┼────┼────┤
│    │    │    │    │
└────┴────┴────┴────┘
```

- 网格中**所有线条都是边框（Border）**；
- 相邻格共享同一条 Border，不存在双线（沿用 FIX-304）；
- 内部分隔线 2px，画布外边框 3px，颜色均为 `#000000`。

#### 3.2.2 单个格子的分层

```
┌───────────────────────────┐
│┌─────────────────────────┐│←- Outline（外描边）
││┌───────────────────────┐││
│││  ┌─────────────────┐  ││←-- Border（边框）即上面网格的边框
│││  │    content      │  │││
│││  └─────────────────┘  │←--- Inner Line（内描边）
││└───────────────────────┘││
│└─────────────────────────┘│
└───────────────────────────┘
```

| 要素 | 位置 | 定义 |
|---|---|---|
| Content | 最内层 | 物品图、角色头像等实际内容 |
| Inner Line | Border 内侧 | 紧贴 Border 内缘的描线 |
| Border | 中间层 | 网格线，参与布局 |
| Outline | Border 外侧 | 不参与布局的外描边 |

### 3.3 重点修复项

#### 3.3.1 当前方格辅助提示框

**结构**：
- **内描边线（Inner Line）**：紧贴 Border 内侧；
- **阴影**：与 **Border** 位置重合，为灰度透明，叠加在 Border 上；
- **不占用** Content 区域，不影响物品渲染。

**视觉层次**
```
      Border（网格线）
        ↑
   ┌─────────┐
   │░░░░░░░░░│  ← 阴影（与 Border 重合，灰度透明）
   │ ┌─────┐ │
   │ │     │ │  ← Inner Line（紧贴 Border 内侧）
   │ │     │ │
   │ └─────┘ │
   └─────────┘
```

#### 3.3.2 区域边界线

**定义**：
- 围绕**区域内方格的外轮廓**绘制 **Border 类型**的描线；
- **在 Border 基础上增加宽度**：Border 为 2px，区域边界线为 4~12px（默认 6px）；
- **两个区域的边界线可以重合展示**：相邻区域交界处各自绘制，不合并、不互相覆盖；
- 线宽参数属于区域属性（`borderWidth`）。

**与网格 Border 的关系**
- 区域边界线覆盖在网格 Border 之上（图层优先级见 §3.4）；
- 交界处视觉可能变粗，属预期。

### 3.4 图层优先级（沿用 v0.3.4，本节不改）

由上至下：

| 序号 | 图层 |
|---|---|
| 1 | 当前方格辅助提示框（鼠标框 / 操作框，见 OPT-A05） |
| 2 | 区域名称 |
| 3 | 物体 |
| 4 | 边框（Border） |
| 5 | 区域边界线 |
| 6 | 不可站立物体阴影 |
| 7 | 区域高亮线 |
| 8 | 方块高亮 |
| 9 | 背景高亮 |
| 10 | 背景 |
| 11 | 空方格 |

## 4. 当前方格辅助提示框拆分

### 4.1 两个提示框

当前方格辅助提示框按**状态不同**拆分为两个独立元素，可同时存在：

| 名称 | 触发条件 | 颜色 | 优先级 |
|---|---|---|---|
| **鼠标提示框** | 鼠标悬停在该格上 | **白色**（含不可站立物品时为中等红色，沿用 v0.3.4 §2.1） | 最高 |
| **操作提示框** | 鼠标点击后，右侧信息抽屉所指的方格 | **蓝色**（`#3B82F6`） | 次高 |

### 4.2 行为

- 鼠标提示框随鼠标移动而**实时切换**；
- 操作提示框在**用户点击某格后**固定在那一格，直到：
  - 用户点击另一格 → 操作提示框移到新格；
  - 用户点击画布外空白 / 按 `Esc` → 操作提示框消失。

### 4.3 视觉叠加

- 当鼠标悬停在**操作提示框所指的格**时：
  - 两个框同时存在；
  - 鼠标提示框（白）优先级更高，覆盖在操作提示框（蓝）之上；
  - 视觉上呈现白色描边在内、蓝色描边在外（或通过不同 z-index 呈现清晰层次）。

### 4.4 与不可站立状态的组合

| 鼠标所在格状态 | 鼠标提示框 | 操作提示框 |
|---|---|---|
| 空格 | 白色 | 蓝色（若有） |
| 含可站立物品 | 白色 | 蓝色（若有） |
| 含不可站立物品 | **中等红色** | 蓝色（若有） |

**验收**
- 悬停任意格 → 出现白色（或红色）提示框；
- 点击任意格 → 出现蓝色提示框并固定；
- 点击另一格 → 蓝色框移动；
- 按 `Esc` / 点击画布外 → 蓝色框消失；
- 鼠标悬停在操作提示框所指格 → 两框叠加呈现层次。

## 5. 地图方格交互颜色优化

### 5.1 高亮色调整

| 用途 | v0.3.4 | v0.3.5 |
|---|---|---|
| 红色高亮 | `#E53935`（或现有偏深红） | **`#EF9A9A`**（淡红） |
| 蓝色高亮 | `#3B82F6` | **`#90CAF9`**（淡蓝） |

**应用范围**
- 方块高亮（角色联动）
- 背景高亮（角色联动）
- 区域高亮线
- 鼠标提示框（不可站立物品时）的红色
- 操作提示框的蓝色

**不调整**
- 参与者主题色、区域颜色、物品本身颜色等用户可配项；
- 网格线、Border 颜色（保持黑色）。

### 5.2 物体阴影加深

| 项 | v0.3.4 | v0.3.5 |
|---|---|---|
| 不可站立物品阴影 | `rgba(0,0,0,0.08)` | **`rgba(0,0,0,0.18)`** |

> 与 §3.1 为同一项，此处再次强调，避免遗漏。

**验收**
- 高亮红 / 蓝色更柔和，不再刺眼；
- 不可站立物品所在格的灰度蒙版明显加深，但仍不遮挡物品图。
