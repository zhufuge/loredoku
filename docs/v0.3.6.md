## 1. 区域高亮线

### 1.1 变更

| 项 | v0.3.5 | v0.3.6 |
|---|---|---|
| 定义 | 区域边界线的内描边线 | 保持不变 |
| 宽度 | 2px | **4px（向内加大）** |
| 位置 | 紧贴区域边界线内侧 | 不变 |
| 颜色 | 蓝色 `#90CAF9` | 不变 |

**说明**
- 高亮线为区域边界线的内描边，紧贴区域边界线的内侧；
- **向内**加大宽度（即向区域内部扩展），不向外扩张；
- 宽度不小于区域边界线宽度的 2/3，保证视觉可辨识；
- 覆盖在区域边界线内侧，不遮挡区域边界线。

### 1.2 视觉示意

```
区域边界线（参数色，6px）
┌────────────────────────────┐
│╔══════════════════════════╗│  ← 区域高亮线（4px，蓝色，向内）
│║                          ║│
│║        区域内容          ║│
│║                          ║│
│╚══════════════════════════╝│
└────────────────────────────┘
```

**验收**
- 区域激活时，内侧可见 4px 蓝色描线；
- 描线紧贴区域边界线内侧，不超出区域边界；
- 描线不遮挡区域内容。

## 2. 地图自适应下边距

### 2.1 问题

v0.3.5 的自适应计算未预留底部工具条高度，导致画布底部被工具条遮挡，或方格实际可用区域被压缩。

### 2.2 修复要求

- 自适应计算时，可用高度**扣除**以下固定值：

| 项 | 固定值 |
|---|---|
| 底部工具条高度 + 上下留白 | **72px** |
| 顶部标尺高度 | 28px |
| 上下内边距 | 16px × 2 |

- 最终可用高度：
  ```
  availableH = 编辑器高度 - 底部工具条留白 72px - 顶部标尺 28px - 内边距 32px
  ```

### 2.3 效果

- 画布底边不再被工具条覆盖；
- 画布居中时，垂直方向保留与工具条的间距；
- 若 `n` 较大导致 `cellSize` 触达下限 90px，允许出现纵向滚动，滚动区域**不包含**工具条。

**验收**
- 任意 `n` 下，画布底部与工具条之间无重叠；
- 工具条悬浮于画布下方留白区，不遮挡任何方格；
- 缩放到下限时仍不遮挡。

## 3. 线条与字体随格子尺寸缩放

### 3.1 问题

v0.3.5 中方格宽度在 [90, 240] 间自适应，但线条宽度、字体大小、标尺字符大小固定不变，导致：
- 小格时线条过粗、字体过大；
- 大格时线条过细、字体过小。

### 3.2 修复要求

引入**基准尺寸**与**缩放系数**：

```
BASE_CELL = 120          // 基准方格宽度
scale = cellSize / BASE_CELL
```

所有与方格相关的线条宽度与字体大小**乘以** `scale`：

| 要素 | 基准值（BASE_CELL = 120 时） | 缩放后 |
|---|---|---|
| 网格线（内部分隔线） | 2px | `2 × scale` |
| 画布外边框 | 见 OPT-B04 | `regionBorderWidth × scale` |
| 内描边 | 1px | `1 × scale` |
| 区域边界线 | 6px（可调 4~12） | `borderWidth × scale` |
| 区域高亮线 | 4px | `4 × scale` |
| 标尺字符 | 15px | `15 × scale` |
| 区域名称字体 | 14px | `14 × scale` |
| 区域名称描边 | 4px | `4 × scale` |

**约束**
- 线条最小可见宽度：`0.5px`（避免小格时线条消失）；
- 线条最大宽度：`12px`（避免大格时线条过粗）；
- 字体最小：`9px`；最大：`28px`。

### 3.3 生效范围

- 所有线条与字体在**渲染时**按当前 `cellSize` 动态计算；
- 用户缩放画布（`Ctrl + 滚轮`）时，`cellSize` 作为基准值不变，缩放通过容器的 `transform: scale(zoom)` 实现，**线条与字体不再二次计算**（避免与 OPT-B03 冲突）；
- 说明：`cellSize` 变化仅发生在窗口 resize / 重置视图 / 更换地图时。

**验收**
- `n = 2` 时方格约 240px，线条与字体明显加粗加大；
- `n = 24` 时方格约 90px，线条与字体明显变细变小；
- 画布缩放（Ctrl + 滚轮）时，线条与字体随容器整体缩放，不出现双重缩放。

## 4. 画布最外边框加粗

### 4.1 变更

| 项 | v0.3.5 | v0.3.6 |
|---|---|---|
| 画布外边框宽度 | 3px 固定 | **与区域边界线宽度一致（默认 6px）** |
| 颜色 | `#000000` | 不变 |

### 4.2 说明

- 外边框宽度取当前地图**所有区域边界线宽度的默认值**（6px）；
- 若用户在某区域调整了 `borderWidth`，外边框**不跟随**，仍保持 6px 默认值；
- 外边框仍乘 `scale`（见 OPT-B03）；
- 外边框位于画布四周，**内部分隔线仍为 2px**（保持区分）；
- 外边框完整覆盖在画布最外层，不被任何物品 / 高亮层遮挡。

### 4.3 视觉层次

```
┌═══════════════════════════┐  ← 画布外边框（6px × scale）
║ ┌───┬───┬───┬───┐         ║
║ │   │   │   │   │         ║  ← 内部分隔线（2px × scale）
║ ├───┼───┼───┼───┤         ║
║ │   │   │   │   │         ║
║ └───┴───┴───┴───┘         ║
└═══════════════════════════┘
```

**验收**
- 画布外边框明显比内部分隔线粗；
- 外边框宽度与区域边界线默认宽度一致；
- 大格 / 小格下外边框与内部分隔线的视觉对比保持合理。

## 5. 标尺字符交互样式

### 5.1 基础样式

| 项 | v0.3.5 | v0.3.6 |
|---|---|---|
| 字号 | 13px | **15px（加大）** |
| 字重 | 600 | 不变 |
| 颜色 | `#1F2937` | **淡灰色 `#9CA3AF`** |
| 背景 | 透明 | 不变 |
| 边框 | 无 | 不变 |

> 字号随 `scale` 缩放（见 OPT-B03）。

### 5.2 鼠标所在方格对应标尺

**触发**：鼠标悬停画布某一格；

**表现**：
- 该格对应的**行号与列号**（顶部标尺的 `Cx` 与左侧标尺的 `Ry`）**颜色加深**；
- 加深色：`#374151`（比基础淡灰更深，但不是纯黑，与"鼠标提示框"的白色区分）；
- **不使用蓝色**；
- **不使用下划线 / 背景块 / 边框**等任何修饰。

### 5.3 操作方格对应标尺

**触发**：鼠标点击画布某格后（即"操作提示框"所在格，见 v0.3.5 §4）；

**表现**：
- 该格对应的行号与列号，在"颜色加深"的基础上**再加大字号**：
  | 状态 | 字号 |
  |---|---|
  | 基础 | 15px × scale |
  | 鼠标所在格 | 15px × scale（不变） |
  | 操作格 | **17px × scale（加大）** |
- 颜色与鼠标所在格相同（`#374151`）；
- 不使用任何其他修饰。

### 5.4 叠加与优先级

| 行 / 列状态 | 表现 |
|---|---|
| 普通 | 淡灰 15px |
| 鼠标悬停 | 深灰 15px |
| 操作格 | 深灰 17px |
| 鼠标悬停 + 操作格 | 深灰 17px（以操作格优先） |

**验收**
- 标尺字符默认为淡灰色，字号明显大于 v0.3.5；
- 悬停画布格 → 对应行号列号变深灰，无蓝色 / 下划线；
- 点击画布格 → 对应行号列号在深灰基础上字号加大；
- 移出鼠标后，鼠标悬停效果消失，操作格效果保留。

## 6. 参与者区调整

### 6.1 标题栏高度

| 项 | v0.3.5 | v0.3.6 |
|---|---|---|
| 标题栏高度 | 36px（与物品栏头部对齐） | **40px（+4px）** |

- 保持与物品栏头部视觉一致：若物品栏头部为 36px，则通过**同步调整物品栏头部为 40px**保持对齐，或接受 4px 差异（推荐同步调整）。

### 6.2 参与者框宽度

| 项 | v0.3.5 | v0.3.6 |
|---|---|---|
| 单元格最小宽度 | 88px | **110px** |
| 单元格最小高度 | 104px | 104px（不变） |
| 头像尺寸 | ≥ 56×56 | 不变 |
| 线索区高度 | 72px | 不变 |
| 单元格间距（gap） | 14px | 不变 |

**布局影响**
- 矩阵列数重新计算，宽高比仍以黄金分割为目标；
- 面板宽度不足时优先减少列数；
- `cols = 1` 仍不足时，面板出现纵向滚动。

### 6.3 参与者序号

- 每个参与者框的**左上角**显示序号（`1`、`2`、`3`……）；
- 编号规则：**从上到下、从左到右**依次递增；
- 第 1 行第 1 列 = `1`，第 1 行第 2 列 = `2`，第 2 行第 1 列 = `3`（若矩阵为 2 列），依此类推；
- 序号与 `characterSlots` 数组顺序一致；
- 样式：
  - 位置：框内左上角，内缩 4px；
  - 背景：半透明白色圆角（`rgba(255,255,255,0.85)`）或纯白；
  - 文字：12px、字重 600、颜色 `#374151`；
  - 描边：1px `rgba(0,0,0,0.1)`，保证在浅色主题色上可读。

**视觉示意**
```
┌──────────────────┐
│ ① [头像]         │  ← 序号在左上角
│                  │
│ ┌──────────────┐ │
│ │ 线索文本…     │ │
│ └──────────────┘ │
└──────────────────┘
```

**验收**
- 标题栏高度 40px，与物品栏头部对齐；
- 参与者框宽度 ≥ 110px；
- 每个框左上角显示序号，编号按从上到下、从左到右；
- 序号在任意主题色下清晰可读。
