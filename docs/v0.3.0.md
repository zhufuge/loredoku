## 1. 优化

### OPT-501 格子内图片禁止拖动

**问题**：浏览器原生 `<img>` 默认支持拖拽，长按或拖拽画布上的物品图片会触发浏览器拖拽行为（拖出一个图片影子），与画布交互冲突。

**修复要求**
1. 所有渲染在画布格子内的物品图、角色头像统一加 `draggable="false"`。
2. 通过 CSS 兜底：
   ```css
   .cell img, .cell [draggable] { -webkit-user-drag: none; user-select: none; }
   ```
3. 同时禁止图片区域的文本选择（`user-select: none`）。
4. 物品抽屉、角色槽位内的图片一并应用相同规则，避免从槽位拖拽角色时同时触发浏览器原生图片拖拽。

**验收**
- 长按 / 拖拽画布内任意物品或角色图片 → 不出现浏览器原生拖拽影子；
- 物品抽屉、角色槽位的拖拽仍走自研 Pointer 拖拽逻辑，不受影响。

### FEAT-502 参与者联动

#### 2.2.1 概念定义

**参与者（Participant）**：指已从角色槽位加入到地图的角色实例。一个角色被放置到地图后，即成为该地图的一个参与者。

参与者除自身的 `characterId` 与坐标外，还带有**地图专属的联动配置**，不修改角色本体数据。

#### 2.2.2 数据结构

地图 JSON（`draft_data` / `versions.data`）中，`placedCharacters` 元素扩展：

```jsonc
{
  "characterId": 5,
  "x": 2, "y": 3,
  "originSlotIndex": 2,
  "mapMeta": { "dialog": "村民A", "questId": "q001" },

  // 新增
  "themeColor": "#FFCC00",            // 参与者主题色，未选为 "#FFFFFF"
  "triggers": [
    {
      "trigger": "click",              // 触发方式：click / touch
      "targets": [
        { "type": "character", "id": 7,   "effect": "highlight", "color": "red" },
        { "type": "item",      "id": 12,  "effect": "highlight", "color": "blue" },
        { "type": "cell",      "x": 3, "y": 4, "effect": "highlight", "color": "red" },
        { "type": "region",    "id": "rg_a1b2c3", "effect": "highlight", "color": "blue" }
      ]
    },
    { "trigger": "touch", "targets": [ /* 同上结构 */ ] }
  ]
}
```

**约束**
- `themeColor`：任意合法十六进制色值，默认 `#FFFFFF`；UI 色板中**不提供蓝色系**（蓝色保留为高亮色）。
- `triggers` 按 `trigger`（`click` / `touch`）分组，两组各自独立维护对象列表。
- `targets[].color`：仅 `red` / `blue` 两个枚举值。
- 通过对象 ID 关联：
  - `character` → `characterId`；
  - `item` → `itemId`；
  - `cell` → 坐标 `(x, y)`；
  - `region` → 区域业务 ID `regionId`。

#### 2.2.3 参与者信息框

**入口**：选择工具点击地图上已放置的角色。

**展示形式**：`Dialog`（居中，宽 560px），标题「参与者：<角色名>」。

**内容布局**

```
┌─ 参与者：村民A ─────────────────────────────────┐
│ [头像(96×96，背景为主题色)]  性别：男           │
│ 角色 ID：villager_a          坐标：C3, R4       │
│                                                 │
│ 主题色：[色板 ▾] 当前 ■ #FFCC00                 │
│                                                 │
│ ── 触发效果 ──                                  │
│ [点击时] [触碰时]   ← Tabs                      │
│                                                 │
│  ▼ 点击时                                       │
│   · 角色 #7 村民B    [高亮] [红/蓝] [删除]      │
│   · 物品 #12 篝火    [高亮] [红/蓝] [删除]      │
│   · 方格 (3,4)       [高亮] [红/蓝] [删除]      │
│   · 区域 森林区      [高亮] [红/蓝] [删除]      │
│   [+ 添加对象]                                  │
│                                                 │
│  ▼ 触碰时                                       │
│   （同上结构）                                  │
│                                                 │
│ [从地图移除]                    [取消] [保存]   │
└─────────────────────────────────────────────────┘
```

**主题色选择器**
- 预设色板：白、黑、红、橙、黄、绿、紫、粉、灰、棕等；
- **不包含任何蓝色系**（`#3B82F6` / `#0EA5E9` 等均剔除）；
- 支持自定义 HEX 输入，但校验时若为蓝色系（`H ∈ [200°, 240°]` 且饱和度足够）→ 弹提示「蓝色为高亮专用色，请选择其他颜色」并拒绝；
- 主题色渲染在角色头像的背景圆环 / 底盘中（头像本身裁剪为圆形，周围或底部使用主题色）。

**触发效果编辑**
- 每个 Tab（点击时 / 触碰时）下为一张对象列表；
- 点击「+ 添加对象」弹出选择器：

  **第一步：选择对象类型**
  ```
  ○ 角色   ○ 物品   ○ 方格   ○ 区域
  ```

  **第二步：选择具体对象**

  | 类型 | 选择方式 |
  |---|---|
  | 角色 | 下拉列出地图上所有参与者角色 |
  | 物品 | 下拉列出当前地图已放置的物品实例（按锚点格唯一定位） |
  | 方格 | 输入 `x, y` 或点击「从画布选择」（临时切换选择模式，点画布空格确定） |
  | 区域 | 下拉列出当前地图所有区域 |

  **第三步：选择颜色**：`红` / `蓝` 两个选项按钮。

- 已添加的条目支持删除；
- 同一对象在同一触发方式下可重复添加（不同颜色），UI 允许；但同对象 + 同颜色去重。

**保存**
- 点击「保存」→ 写入 `placedCharacters[].themeColor` 与 `placedCharacters[].triggers`；
- `dirty = true`，入撤销栈；
- Toast「已保存参与者配置」。

#### 2.2.4 效果渲染（编辑器内）

当点击 / 触碰某参与者时，按 `triggers` 配置触发对应对象的**高亮效果**：

| 对象 | 效果 | 渲染 |
|---|---|---|
| 角色 | 高亮角色 | 角色头像外圈以参数色（红 / 蓝）描边 3px + 轻微放大 `scale 1.08`，持续 1s 后恢复 |
| 物品 | 高亮物品 | 物品图外覆盖一层半透明参数色蒙层（`opacity 0.45`），持续 1s |
| 方格 | 高亮方格 | 该格背景层临时渲染为参数色纯色块（覆盖原背景层物品），持续 1s |
| 区域 | 高亮区域 | 区域内所有格背景层临时渲染为参数色纯色块，持续 1s |

**触发时机**
- **点击**：用户在编辑器或预览页用鼠标单击参与者（左键）；
- **触碰**：鼠标进入参与者所在格的瞬间（`pointerenter`），或移动端手指触碰（`touchstart`）；
- 两者互不冲突，可同时配置。

**高亮期间**
- 多个对象同时高亮不叠加（后触发覆盖前触发的同类对象）；
- 高亮 1s 后自动淡出；
- 拖动 / 缩放画布不打断高亮；
- 高亮层位于物品层之上、网格线之下。

#### 2.2.5 撤销与持久化

- 参与者信息框内的所有修改（主题色、触发列表）作为**单次原子操作**入撤销栈；
- 地图 JSON 中的 `placedCharacters` 结构随草稿保存到后端；
- 发布时带入 `versions.data`。

#### 2.2.6 接口

- 地图保存接口（`PUT /api/projects/:id/map`）已支持全量 `draft` 提交，无需新增字段声明；
- 服务端 zod schema 补充 `placedCharacters[].themeColor` 与 `placedCharacters[].triggers` 的校验：
  - `themeColor` 为 `#RRGGBB`；
  - `triggers` 为数组，`trigger ∈ {click, touch}`；
  - `targets` 数组，`type ∈ {character, item, cell, region}`，`color ∈ {red, blue}`；
  - 引用对象（角色 / 物品 / 区域 / 方格）必须在地图数据中存在。

**验收**
- 点击已放置角色 → 弹出参与者信息框；
- 可选择主题色（蓝色不可选）；
- 可为「点击时」「触碰时」分别添加多对象、多效果；
- 保存后再次打开信息框配置保留；
- 在编辑器点击 / 触碰该参与者，能触发配置的高亮效果；
- 撤销 / 重做正常；
- 刷新页面后配置保留（需先保存）。

### FEAT-503 作品管理独立面板 + 效果预览

> 本模块原称「版本」，本版更名为「**作品**」，路由 `/works`，语义为"已定稿、可展示的成品"。

#### 2.3.1 作品管理独立面板

**入口**
- 顶部导航新增一级入口「**作品**」（位于「地图 / 物品 / 角色」之后），路由 `/works`；
- 页面内可通过地图下拉切换查看不同地图的作品。

**面板内容**

```
┌─ 作品管理 ────────────────────────────────────────────┐
│ 地图：[新手村 ▾]                                       │
│                                                       │
│ 作品列表：                                             │
│ ┌───────────────────────────────────────────────────┐ │
│ │ v3  · 2026-05-10 12:00  · 6×6  · 备注...          │ │
│ │     [查看效果]  [导出]  [基于此作品创建草稿]  [删除]│ │
│ ├───────────────────────────────────────────────────┤ │
│ │ v2  · 2026-05-08 09:30  · 6×6                     │ │
│ │     [查看效果]  [导出]  [基于此作品创建草稿]  [删除]│ │
│ └───────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────┘
```

**每项操作**

| 操作 | 说明 |
|---|---|
| 查看效果 | 跳转到 `/works/:workId/view`（见 2.3.2） |
| 导出 | 下载该作品的 JSON 快照 |
| 基于此作品创建草稿 | 调用 `POST /api/projects/:id/versions/:versionNo/draft` |
| 删除 | 二次确认，弹窗等待响应后再关闭（沿用 OPT-210） |

**列表信息**
- 作品编号、发布时间、`gridSize`、备注；
- 缩略信息：参与者数 / 区域数 / 物品数。

**空状态**
- 「暂无作品，发布一个试试」。

#### 2.3.2 效果预览页

**路由**：`/works/:workId/view`

**布局**

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：← 返回作品列表 | 地图名 v3 | 缩放 -/+                     │
├────────────────┬─────────────────────────────────────────────┤
│  参与者区域     │  地图（只读）                                │
│  （左侧）       │                                              │
│                │   ┌──┬──┬──┬──┬──┬──┐                       │
│ [头像+主题色]   │   │  │  │  │  │  │  │                       │
│  村民A          │   ├──┼──┼──┼──┼──┼──┤                       │
│ [头像+主题色]   │   │  │  │  │  │  │  │                       │
│  村民B          │   ├──┼──┼──┼──┼──┼──┤                       │
│ [头像+主题色]   │   │  │  │  │  │  │  │                       │
│  村民C          │   └──┴──┴──┴──┴──┴──┘                       │
│                │                                              │
│ [点击时] [触碰时]│                                              │
└────────────────┴─────────────────────────────────────────────┘
```

**只读特性**
- 地图内容不可编辑：不显示物品抽屉、不显示橡皮擦、不显示尺寸调整、不显示保存 / 发布；
- 允许的操作：平移、缩放、点击选中参与者、切换查看触发效果的 Tab。

**左侧参与者区域**
- 竖直排列所有参与者：头像（背景为主题色）+ 名称 + 性别标签；
- 顶部提供两个 Tab：`[点击时] [触碰时]`，切换后左侧列表行为改变（见下）；
- 单击某个参与者 → 地图上该参与者高亮（主题色描边），并触发其「点击时」或「触碰时」配置（根据当前 Tab）的**预览效果**：
  - 所有配置的目标对象按规则高亮；
  - 高亮持续 1s 后自动淡出；
  - 若配置了多个对象，全部同时高亮。

**悬停预览**
- 悬停左侧参与者列表项 → 该参与者在地图上以主题色描边高亮（不触发配置）；
- 移出后恢复。

**触碰预览（Tab = 触碰时）**
- 鼠标进入地图上某参与者所在格 → 触发该参与者的「触碰时」配置效果；
- 用于模拟真实交互。

**缩放与平移**
- 与编辑器一致的交互：`Space + 拖拽`、`Ctrl + 滚轮`、`Ctrl + 0` 重置；
- 缩放百分比与编辑器保持一致的工具条（只保留缩放部分）。

#### 2.3.3 与编辑器的一致性

- 预览页的高亮效果渲染逻辑与编辑器**完全复用同一套组件**，避免两处逻辑漂移；
- 复用范围：物品渲染、角色渲染、区域边框渲染、高亮层渲染；
- 差异点仅在于：预览页所有编辑入口不可用，且数据源来自 `versions.data` 而非 `draft_data`。

#### 2.3.4 接口

复用现有：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/projects/:id/versions` | 作品列表 |
| GET | `/api/projects/:id/versions/:versionNo` | 某作品完整数据 |
| POST | `/api/projects/:id/versions/:versionNo/draft` | 基于作品创建草稿 |
| DELETE | `/api/projects/:id/versions/:versionNo` | 删除作品 |

无新增接口。

**验收**
- 顶部导航出现「作品」入口；
- 作品列表按时间倒序展示，含作品编号、时间、尺寸、备注；
- 点击「查看效果」进入预览页；
- 预览页左侧参与者列表展示头像 + 主题色背景；
- 单击参与者 → 地图上触发对应触发方式的配置效果；
- 切换「点击时 / 触碰时」Tab，触发行为随之切换；
- 预览页不可编辑任何内容；
- 从预览页返回作品列表正常。
