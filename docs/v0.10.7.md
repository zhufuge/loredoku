## §2 区域标题默认位置：支持 `defaultLabelCell`

### 问题

`DraftRegion.labelCell` 是唯一的标题位置字段，由 `computeLabelCell()` 自动算出：区域**最底部行中央**。作者添加区域后无法把标题固定到别处——每次编辑都会被重算回底部行中央。

### 做法

- `packages/shared/src/types/domain.ts`：`DraftRegion` 新增 **`defaultLabelCell?: [number, number] | null`**（可选，缺省 `undefined` = 保持现有自动计算，兼容旧数据与旧 bundle）。
- `packages/web/src/lib/region.ts`：`computeLabelCell(cells, defaultLabelCell?)` 新增第二个可选参数；若提供 `defaultLabelCell`，直接返回它，否则按原有逻辑算底部行中央。
- `packages/web/src/stores/editorStore.ts`：
  - `RegionInput` 新增 `defaultLabelCell?: [number, number] | null`；
  - `createRegion` / `updateRegion` / `setGridSize` 调用 `computeLabelCell` 时把 `defaultLabelCell` 传进去，`updateRegion` 同时保留原有区域的 `defaultLabelCell`（若新输入未覆盖）。

### 验证

`src/lib/region.test.ts` 新增 2 条：`defaultLabelCell` 优先 / 缺省退回自动计算。

## §3 地图编辑点击区域标题弹信息框（与谜题/游戏做区别）

### 问题

v0.10.2 后，区域标签已从 `<button>` 改成 `<span>`，点击不再被 `stopPropagation()` 拦截，而是冒泡到画布容器按格子换算。地图编辑里，点击区域标题应该**弹出该区域的信息框**；谜题编辑器、游戏页的区域标签只做悬停，不弹窗。

### 做法

- `packages/web/src/components/map/MapOverlayLayers.tsx`：`MapRegionLabelLayer` 新增可选 prop `onSelect?: (id: string) => void`；标签 `<span>` 挂 `onClick={(event) => { event.stopPropagation(); onSelect?.(region.id); }}`，与 `onHover` 并存（悬停点亮、点击弹窗）。`stopPropagation()` 是关键：v0.10.2 刻意把标签从 `stopPropagation()` 的 `<button>` 改成点击冒泡到画布容器，否则点标题会把标签下面那一格也选中；加了 `onSelect` 后必须重新拦截，让点标题只选区域、不选底下格子。
- `packages/web/src/components/map-editor/EditorCanvas.tsx`：新增可选 prop `onSelectRegionLabel?: (id: string) => void`，透传给 `MapRegionLabelLayer`。
- `packages/web/src/pages/MapEditorPage.tsx`：传入 `onSelectRegionLabel`，点击时 `guardMapInfo(() => { editor.setSelectedRegion(regionId); setInfoOpen(true); })`——选中区域并打开右侧信息框。
- `packages/web/src/pages/PuzzleEditorPage.tsx`：**不传** `onSelectRegionLabel`，行为不变（只悬停不弹窗）。

### 验证

`src/components/map/MapRegionLabelLayer.test.tsx` 新增「点击区域标签回调 `onSelect` 传出区域 id」。
