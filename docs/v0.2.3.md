## 1. 编辑器

### OPT-201 默认展示背景层

- 进入编辑器时，图层切换器默认选中 **背景层**（`activeLayer = 'background'`）；
- 图层顺序保持「背景层在下、物件层在上」，不因默认选中而改变渲染顺序；
- 从其他页面返回编辑器、切换地图项目时均重置为背景层。

**验收**
- 首次进入编辑器，底部工具条上的图层指示器为「背景」高亮；
- 拖入背景物品落到背景层，拖入物件物品落到物件层，行为与图层选择一致。

---

### OPT-202 画布最小尺寸放宽

| 项 | 原值 | 新值 |
|---|---|---|
| `gridSize` 最小值 | 3 | **2** |
| `gridSize` 最大值 | 24 | 24（不变） |
| 新建项目默认值 | 6 | 6（不变） |

**需同步变更的位置**
- 数据库 `map_projects.grid_size` 的 `CHECK` 约束改为 `2 <= grid_size <= 24`；
- 后端 zod schema 校验改为 `min(2).max(24)`；
- 前端 `Slider` 与 `NumberInput` 的 min 改为 2；
- 画布尺寸调整弹窗、新建项目弹窗同步更新。

**验收**
- 可创建 `2 × 2` 的地图；
- 尝试创建 `1 × 1` 或 `25 × 25` 被拒绝并提示。

### OPT-203 画布尺寸调整交互重构

**问题**
- 调整入口不直观（藏在项目名旁的 `n × n` 标签）；
- 拖动 Slider 立即生效，无法预览与取消。

**新交互**

1. **入口位置**
   - 移到底部工具条，作为独立按钮「画布尺寸」（图标 + 当前 `n × n` 文本）；
   - 点击后弹出居中 `Dialog`。

2. **弹窗内容**
   - 顶部展示当前尺寸：`当前：6 × 6`；
   - Slider（2~24）+ NumberInput（2~24），二者双向联动；
   - 画布预览缩略图：实时以浅灰底 + 绿色框表示**保留区**，红色斜纹表示**将被裁掉**的区域（仅在变小时展示）；
   - 若缩小会导致物品被裁、角色被撤、区域被截，弹窗底部以列表形式列出受影响对象：
     ```
     将被移除：
     · 物品「桌子」(2×1) 位于 C5,R4
     · 区域「森林区」部分格子越界（3 格）
     · 角色「村民A」将被撤回槽位
     ```
   - 底部按钮：`[取消] [确认调整]`。

3. **生效时机**
   - 只有点击「确认调整」才真正调用 `PATCH /api/projects/:id/grid-size`；
   - 请求期间按钮进入 loading，禁止重复点击；
   - 成功后刷新本地状态并 Toast 提示；
   - 失败则弹窗保持打开，展示错误。

4. **取消行为**
   - 关闭弹窗，画布尺寸保持不变；
   - 不影响历史栈与 `dirty` 状态。

**验收**
- 打开弹窗调整数值不会立即改变画布；
- 点「确认调整」后画布才变化；
- 变小时弹窗内可见将被移除的清单；
- 取消后画布完全不变。

### OPT-205 物品图融入格子

**问题**
- 物品缩略图渲染时溢出格子、覆盖相邻网格线，视觉上破坏网格。

**修复要求**
- 物品图渲染使用 `object-fit: cover`（或按物品宽高比 `contain`），并**严格裁剪在格子内**：
  ```css
  .cell-item {
    position: absolute;
    inset: 0;
    overflow: hidden;
    border-radius: 0;       /* 与格对齐，不加圆角 */
  }
  .cell-item img {
    width: 100%;
    height: 100%;
    object-fit: cover;
    display: block;
  }
  ```
- 多格物品：容器覆盖其占位的整块矩形，内部图片拉伸至整块，**不跨越网格线**；
- 网格线（2px 黑色）绘制层级**高于物品图**，保证网格线始终完整可见；
- 若物品图原始宽高比与占位比例不一致，默认 `cover` 裁切；提供物品管理页开关 `fitMode: 'cover' | 'contain'`（默认 `cover`），`contain` 时容器内居中并留白。

**验收**
- 任意物品落格后，图不溢出、不遮挡任何网格线；
- 多格物品完整覆盖其占位区域，边界与网格线对齐。

### OPT-206 保存请求 loading

- 点击顶栏「保存」后立即进入 `saving` 状态：
  - 按钮内展示 `Loader2` 图标旋转；
  - 按钮文案变为「保存中…」；
  - 按钮 `disabled`，防止重复提交；
- 请求返回成功 → 退出 `saving`，Toast「已保存」；
- 请求失败 → 退出 `saving`，Toast 错误信息，按钮恢复可点击；
- `saving` 期间 `Ctrl/Cmd + S` 快捷键不触发新的保存；
- 自动保存（若开启）同样遵循以上规则，且不干扰手动保存的 loading 展示。

**验收**
- 手动保存期间按钮呈现 loading 且不可点击；
- 保存完成后按钮恢复。

## 2. 导入 / 导出

### OPT-208 导入支持回退

**问题**
- 导入地图后直接覆盖当前编辑器状态，且**清空撤销栈**，无法回退到导入前。

**修复要求**

1. **导入作为一个可撤销操作**
   - 导入前记录当前完整快照（`cells / regions / characterSlots / placedCharacters / gridSize`）；
   - 将该快照 `push` 到 `history.past` 栈顶，`history.future` 清空；
   - 应用导入数据；
   - `dirty = true`。

2. **撤销栈保留**
   - 导入**不清空**历史，仅作为一次普通操作追加；
   - `Ctrl/Cmd + Z` 可撤回到导入前状态，`Ctrl/Cmd + Shift + Z` 可重做导入。

3. **确认弹窗**
   - 导入前展示 `AlertDialog`：
     ```
     导入将覆盖当前编辑内容，是否继续？
     [取消] [继续导入]
     ```
   - 只有在编辑器 `dirty === false` 时才可选跳过该弹窗（保留行为一致）；
   - 若编辑器 `dirty === true`，额外提示「当前修改未保存，导入后可撤销但不会自动保存」。

4. **导入失败**
   - 校验失败 → 保持原状态，不写入历史，展示具体错误位置。

**验收**
- 导入后按 `Ctrl/Cmd + Z` 能恢复到导入前的地图内容；
- 导入前后历史栈条目数量递增，未清空；
- 导入失败时状态与历史均不变。

## 3. 物品 / 角色生命周期

### OPT-209 启用、停用、删除按钮语义化

**背景**
- 原实现中「删除」仅做软删除（`is_active = false`），用户无法彻底清除；
- 按钮语义混乱，无法区分停用与删除。

**新规则**

| 状态 | 可用操作 | 说明 |
|---|---|---|
| 启用中（`is_active = true`） | **停用** | 变为停用状态，不在编辑器物品栏/角色栏展示，但已引用的地图数据保留 |
| 停用中（`is_active = false`） | **启用** | 恢复为启用状态 |
| 停用中（`is_active = false`） | **删除**（彻底） | 从数据库中**物理删除**，删除前需处理引用 |

**按钮展示**
- 物品管理页、角色管理页列表中每项右侧操作区：
  - 启用状态：`[编辑] [停用]`
  - 停用状态：`[编辑] [启用] [删除]`
- 编辑器中引用停用物品的地图**不报错**，物品栏中不展示停用项。

**物理删除的处理**
- 点击「删除」→ 弹窗提示：
  - 若未被任何地图引用：
    ```
    确定彻底删除「桌子」吗？此操作不可恢复。
    [取消] [删除]
    ```
  - 若被引用（`/usages` 非空）：
    ```
    「桌子」正被 N 个地图使用。
    [取消] [仅停用] [删除并清空引用]
    ```
    - 「仅停用」→ 仅设 `is_active = false`；
    - 「删除并清空引用」→ 物理删除物品记录，同时把引用该物品的地图 JSON 中相关格子清空（**不修改历史版本 `map_versions.data`**，仅处理 `draft_data`）；
- 删除成功后刷新列表与相关缓存。

**接口补充**

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/items/:id/enable` | 启用 |
| POST | `/api/items/:id/disable` | 停用 |
| DELETE | `/api/items/:id?hard=true` | 彻底删除（`hard=true` 时物理删除） |
| POST | `/api/characters/:id/enable` | 启用角色 |
| POST | `/api/characters/:id/disable` | 停用角色 |
| DELETE | `/api/characters/:id?hard=true` | 彻底删除角色 |

**验收**
- 启用态只能停用，停用态可启用或彻底删除；
- 彻底删除后列表不再出现该记录，重新加载页面也不会出现；
- 被引用的物品删除时给出「仅停用 / 删除并清空引用」选项。

### OPT-210 删除确认弹窗等待响应

**问题**
- 点击确认删除后弹窗立即关闭，用户可能连续点击造成重复请求或误删。

**修复要求**
- 弹窗「删除」按钮点击后：
  1. 按钮立即进入 loading 状态（`Loader2` 旋转），文案「删除中…」；
  2. 按钮 `disabled`，另一按钮「取消」同步 `disabled`；
  3. 弹窗整体 `pointer-events: none`，防止遮罩点击关闭；
  4. 等待接口返回；
- 成功 → 关闭弹窗 → Toast「已删除」→ 刷新列表；
- 失败 → 弹窗保持打开 → 按钮恢复 → Toast 错误信息。

**适用范围**
- 物品删除、角色删除；
- 地图项目删除；
- 版本删除；
- 任何其他二次确认的删除操作。

**验收**
- 点击删除后弹窗不立即消失，直到接口返回；
- loading 期间无法重复点击或关闭弹窗；
- 失败时可在同一弹窗内重试。

## 5. 区域

### OPT-213 区域边框去除阴影

- 区域边框渲染时**去掉** `filter: drop-shadow(...)`；
- 选中或悬停时的状态区分改为：
  - 线宽 `+2px`；
  - 边框色不透明度 `100%`（未选中时为 `70%`，形成对比）；
- 不再使用任何发光/阴影。

**验收**
- 区域边框在任意状态下均无阴影/发光效果；
- 选中态通过线宽与不透明度差异可辨识。

---

### OPT-214 区域名称标签位置与样式

**位置变更**
- 原：区域**最下方行**的居中格**下方**；
- 新：区域**最下方行**的居中格**上方**（紧贴该格的顶部内边缘，视觉上位于格内上半部分）。

**样式变更**

| 项 | 原 | 新 |
|---|---|---|
| 背景 | 圆角胶囊，区域色 | **无背景** |
| 文字颜色 | 按对比度自动黑/白 | **白色** |
| 文字粗细 | 常规 | **加粗（`font-weight: 700`）** |
| 描边 | 无 | **黑色描边 2px**（`-webkit-text-stroke: 2px #000` 或 `text-shadow` 组合模拟） |
| 圆角 | 有 | 无 |
| 字号 | 11px | 12px |

**参考 CSS**
```css
.region-label {
  position: absolute;
  pointer-events: auto;
  color: #FFFFFF;
  font-weight: 700;
  font-size: 12px;
  -webkit-text-stroke: 2px #000000;
  paint-order: stroke fill;
  background: none;
  border-radius: 0;
  text-align: center;
}
```

**悬停行为**
- 悬停标签 → 该区域边框高亮（线宽 +2px，不透明度 100%），**无阴影**；
- 悬停时标签本身字号 `+1px` 或提高描边宽度（可选），不做阴影。

**验收**
- 标签位于区域最下方行的居中格**上方**；
- 白字黑描边、无背景、无圆角；
- 悬停标签区域边框高亮（无线阴影）。

### OPT-215 区域选择状态下禁止拖动

**问题**
- 进入区域选择模式后，仍可拖动格子上的物品或角色，导致误操作。

**修复要求**
- `activeTool === 'region'`（构建选区的整个周期内）时：
  - 画布上的物品、角色**不响应拖拽**；
  - `pointer-events` 保持在选区层，物品/角色层设为 `pointer-events: none`；
  - 光标保持为「十字」或区域工具图标；
  - 物品栏、角色槽位同样禁止拖拽（置灰或忽略 `pointerdown`）；
- 退出区域工具后恢复正常拖拽。

**验收**
- 区域选择模式下尝试拖动任何物品/角色均无反应；
- 该模式下仍可正常点击/拖拽画布累积选区；
- 切换回选择工具后拖拽恢复正常。

---

### OPT-216 区域矩形选择修复；移除多边形

**问题**
- 矩形选择仍存在只能选中单个格的情况（未完全展开起止点矩形）。

**修复要求**
1. **矩形选择**
   - `pointerdown` 记录起点格 `(x0, y0)`；
   - `pointermove` 实时更新终点格 `(x1, y1)`，绘制预览矩形；
   - `pointerup` 按 `x ∈ [min(x0,x1), max(x0,x1)]`、`y ∈ [min(y0,y1), max(y0,y1)]` **展开全部格**加入选区；
   - 拖拽阈值 ≥ 4px 才进入框选态，避免误触；
   - 按住 `Shift` 拖拽为追加，按住 `Alt` 拖拽为减选；
   - 单击切换单格选中状态。

2. **移除多边形模式**
   - 删除工具条上的「多边形」切换按钮；
   - 删除相关状态字段 `regionShape` 中的 `polygon` 选项；
   - 移除相关代码路径与测试用例。

3. **保留自由笔刷（可选）**

## 7. 标尺

### OPT-218 标尺贴边地图方格

**问题**
- 原标尺贴在编辑器容器边缘，与地图方格之间存在空隙，视觉上未对齐。

**修复要求**
- 标尺必须**紧贴地图方格的上方与左侧**：
  - 顶部标尺的下边缘与地图方格的第 1 行顶部**严格对齐**（无间隙）；
  - 左侧标尺的右边缘与地图方格的第 1 列左侧**严格对齐**（无间隙）；
- 标尺随地图容器一起平移/缩放（作为地图的兄弟节点放在同一 `transform` 容器内，或使用同一容器 `translate` 联动）；
- 标尺自身的字号与厚度**不随缩放**变化（保持可读），但位置跟随；
- 当画布平移到视口边缘时，标尺贴住地图而**不是贴住视口**；
- 左上角交叉区（`28×28`）与标尺同色，作为对齐基准。

**验收**
- 缩放、平移画布，标尺始终紧贴地图方格左上角；
- 标尺与方格之间无任何可见空隙；
- 标尺位置与行列号严格对齐。
