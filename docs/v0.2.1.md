## 1. Bug 修复

### BUG-01 编辑器未保存离开拦截完全失效

**现象**
在编辑器修改内容后点击浏览器返回：
- 无任何提示弹窗；
- 页面也不返回；
- 点击页面内「返回」按钮同样无效。

**根因分析**
1. 路由仍使用 `<BrowserRouter>`，`useBlocker` 在非 Data Router 环境下**直接抛错或被忽略**，导致拦截完全不生效。
2. 弹窗 `open` 由本地 `useState` 控制，与 `blocker.state` 不同步；点击「离开」时先 `setOpen(false)` 再 `blocker.proceed()`，React 提交前 `proceed` 已被覆盖。
3. 页面内「返回」按钮直接调用 `navigate(-1)`，绕过所有拦截逻辑。

**修复要求**

1. **路由改造（硬性）**
   - 使用 `createBrowserRouter` + `RouterProvider` 构建路由；
   - 所有 `<Link>` / `useNavigate` / 页面内返回按钮均走同一 Data Router 上下文。

2. **统一拦截 Hook `useUnsavedChangesGuard(dirty: boolean)`**
   - 弹窗 `open` 状态**唯一来源**：`blocker.state === 'blocked'`，禁止使用独立 `useState`；
   - 点击「离开」：`requestAnimationFrame(() => blocker.proceed())`；
   - 点击「取消」：`blocker.reset()`；
   - `beforeunload` 拦截关闭/刷新标签页；
   - `popstate` 兜底：300ms 后若 URL 未变、`dirty` 仍为 true、弹窗已关闭，则 `history.go(-1)`。

3. **页面内返回按钮**
   - 编辑器顶栏「← 返回」必须通过 `navigate('/projects')` 触发，`dirty` 时由 `useBlocker` 拦截；
   - 禁止在按钮 onClick 中直接 `window.history.back()`。

4. **兜底校验**
   - 集成测试覆盖以下场景：修改→点浏览器返回→弹窗出现；点「离开」→成功返回；点「取消」→停留；修改→点页面返回→弹窗出现；刷新→浏览器原生提示。

**验收标准**
| 场景 | 期望 |
|---|---|
| 修改后点浏览器返回 | 弹窗出现 |
| 弹窗点「离开」 | 弹窗关闭，成功返回上一页 |
| 弹窗点「取消」 | 弹窗关闭，停留编辑器 |
| 修改后点页面「← 返回」 | 同上三种行为一致 |
| 修改后刷新/关闭标签页 | 浏览器原生 beforeunload 提示 |

### BUG-02 区域框选每次只能选中一格

**现象**
使用「框选区域」工具在画布上拖拽时，松开鼠标后仅高亮了一个格子。

**根因分析**
- 拖拽过程中未记录 `pointerdown` 起点；
- `pointermove` 未实时更新选区终点；
- `pointerup` 仅把当前悬停格加入选中集合，未使用起止矩形展开。

**修复要求**

1. **矩形模式**
   - `pointerdown` 记录起始格 `(x0, y0)`；
   - `pointermove` 更新终点格 `(x1, y1)`，实时渲染虚线选框；
   - `pointerup` 按 `x ∈ [min(x0,x1), max(x0,x1)]`、`y ∈ [min(y0,y1), max(y0,y1)]` 展开全部格加入选区；
   - 选区以**集合**形式存储（`Set<"x,y">`），避免重复。

2. **多边形模式**
   - 单击依次记录顶点（吸附到格点）；
   - 双击闭合，按射线法把多边形覆盖的所有格加入选区。

3. **自由笔刷模式**
   - `pointerdown` 进入绘制态；
   - `pointermove` 每进入新格即加入选区；
   - 按住 `Alt` 时改为减选；
   - `pointerup` 结束绘制。

4. **拖拽阈值**
   - `pointermove` 位移小于 4px 时不进入框选态，避免误触。

5. **选区可视化**
   - 选中格显示半透明蓝罩（`rgba(59,130,246,0.25)`）+ 1px 蓝色内描边；
   - 选区上覆盖层 `pointer-events: none`。

**验收标准**
- 拖拽矩形可一次选中多个格；
- 多边形、自由笔刷模式均可选中任意连通集合；
- 选区格数与鼠标拖过的格子集合一致。

### BUG-03 区域确定后所选格子变全黑

**现象**
添加区域后，所选区域格子被纯黑填充完全覆盖，看不到底下的物品与网格。

**根因分析**
- 上一版把区域默认 `fillOpacity` 定为 `1`（不透明），与"区域只需边框"的实际诉求不符。

**修复要求（同时修正 v0.2.0 的 OPT-04 结论）**

| 项 | v0.2.0 规定 | 修正为 |
|---|---|---|
| 区域默认颜色 | `#000000` | **`#000000`**（不变） |
| 区域默认 `fillOpacity` | `1`（不透明） | **`0`（完全透明）** |
| `fillOpacity` 取值范围 | 0~1 | **0~1**（不变） |
| `borderWidth` 默认 | 4px | **4px**（不变） |

**渲染规则**
- 区域默认**仅渲染边框**，内部完全透明，网格、背景层、物件层、角色均可正常显示；
- 用户在区域信息面板中可手动调整 `fillOpacity`（0~1），高于 0 时按色值 + 透明度叠加填充；
- 移除图层面板上「区域填充临时透明化」开关（已无必要）。

**验收标准**
- 新建区域后，区域内可清晰看到底层网格与物品；
- 区域边界线明显粗于网格线；
- 手动调高 `fillOpacity` 时填充可正常显示。

## 2. 缺失功能补齐

### MISS-01 区域选择与展示完整功能

> 以下功能在 v0.2.0 中已描述，但验收时未实现，本版必须补齐。

#### 2.1.1 任意连通形状选择

底部工具条切换形状模式：

| 模式 | 交互 |
|---|---|
| 矩形 | 拖拽出矩形框（修复见 BUG-02） |
| 多边形 | 依次单击顶点，双击闭合；顶点吸附格点 |
| 自由笔刷 | 按住拖过加入；`Alt + 拖拽` 减选 |

- 完成选择后弹出区域信息弹窗（名称、区域标识 ID、颜色、线宽、填充透明度）；
- **连通性校验**：所选格子必须 4-邻接连通，否则拒绝保存并提示"区域必须是相连的方格"；
- 与已有区域冲突时提示「覆盖 / 跳过冲突格」。

#### 2.1.2 区域标识 ID

- 每个区域除名称外必须有唯一业务 ID：`regionId`（短 uuid，如 `rg_a1b2c3`）；
- 项目内唯一，仅字母数字下划线；
- 创建时默认自动生成，可手动编辑；
- 存入地图 JSON 的 `regions[].id`；
- 区域信息面板中必须展示该 ID。

#### 2.1.3 名称标签位置

- 取区域中 `y` 最大的行（最下方行）；
- 在该行的区域格子里取 `x` 中位数的格子作为 `labelCell`；
- 结果写入 `regions[].labelCell`；
- 标签以胶囊形渲染：背景为区域颜色、文字按对比度自动取黑/白、字号 11px；
- 标签层 `z-index` 位于物件层之上、角色层之下；
- 标签 `pointer-events: auto`，可点击、可悬停。

#### 2.1.4 悬停高亮

- 悬停区域名称标签 → 该区域**边框高亮**：`borderWidth + 2px`，附加 `filter: drop-shadow(0 0 4px <color>)`；
- 同时区域内所有物品轻微高亮（外发光）；
- 鼠标移出后恢复。

**验收标准**
- 三种形状模式均可选择任意连通格子集合；
- 区域有唯一 ID，可在信息面板查看与编辑；
- 名称标签出现在区域最下方行的居中格；
- 悬停标签时区域边框明显高亮。

**位置与尺寸**

- 左侧标尺：位于画布正左侧，宽度 28px，标 `R1 R2 ... Rn`；

| 项 | 值 |

| 文字色 | `#374151` |
| 字号 | 11px |
| 边框 | 底部（顶部标尺）/ 右侧（左侧标尺）1px `#E5E7EB` |

- 随画布平移同步滚动（同一 `translate` 容器或联动 `scrollLeft/Top`）；

- 列号/行号从 1 开始。

**验收标准**
- 画布上方可见 `C1..Cn` 标尺，左侧可见 `R1..Rn` 标尺；
- 拖动网格时标尺同步移动；
- 悬停任一格，对应行号列号高亮。

### MISS-04 右侧信息抽屉

**位置与样式**
- 位于画布右侧，宽度 320px；
- 初始收起，仅显示竖直把手（宽 8px，圆角）；
- 点击任意对象后自动展开；
- 收起按钮位于抽屉右上角。

**展开触发场景**

| 场景 | 展示内容 |
|---|---|
| 选择工具点击单个格子 | 见下方「格子信息结构」 |
| 点击区域名称标签 | 见下方「区域信息结构」 |
| 点击已放置角色 | 弹出 `Dialog`（非抽屉），见下方「角色信息结构」 |
| 点击空白处 | 收起抽屉 |

**格子信息结构**
```
坐标：C{x+1}, R{y+1}
【背景层】 缩略图 / 名称 / ID / 触发信息
【物件层】 缩略图 / 名称 / ID / 多格尺寸 / 可站立标识
【角色】   头像 / 名称（点击展开编辑）
【所属区域】 名称 + 区域 ID（点击选中该区域）
快捷操作：[清空本格] [清空物件层]
```

**区域信息结构**
```
名称 / 区域 ID / 颜色 / 边界线宽 / 填充透明度 / 包含格子数
操作：[编辑] [定位到区域] [删除]
```

**角色信息结构（Dialog）**
- 头像、名称、ID、当前坐标（只读）；
- **地图关联信息编辑器**：自由键值对（如 `dialog`、`questId`、`trigger`），写入 `placedCharacters[].mapMeta`；
- 若所在格不可站立，显示红色警告；
- 操作：确认 / 取消。

**验收标准**
- 点击格子/区域标签/角色，抽屉或弹窗按要求展示信息；
- 角色地图关联信息可编辑并保存；
- 抽屉可手动收起与展开。

## 3. 布局调整

### LAYOUT-01 角色槽位区重新定位

**变更点**
- 角色槽位区**不与工具/选择区放在一起**；
- 位置调整为：**工具栏右侧、画布左侧**，独立成列；
- 默认渲染 `n` 个槽位（与 `gridSize` 一致）；
- 支持通过拖拽调整槽位中角色的顺序。

**位置与尺寸**
| 项 | 值 |
|---|---|
| 位置 | 画布左侧，紧贴画布（含标尺列之后） |
| 宽度 | 72px |
| 槽位尺寸 | 56×56 |
| 槽位间距 | 8px |
| 列顶部 | 显示 `已放置 x/n` 计数 |

**槽位行为**
- 空槽：虚线边框 + 浅灰背景；
- 已填充：角色头像 + 名称 tooltip；
- 从角色抽屉拖拽角色到空槽 → 填充；
- 从槽位拖拽角色到**可站立**格子 → 完成放置，槽位清空；
- 从地图拖回槽位 → 撤下角色；
- 拖动槽位内角色到另一槽位 → **交换/重排顺序**，两个槽位位置上的角色互换；
- 重排时显示插入位置指示（蓝色横线）。

**整体布局示意**
```

│ 顶栏                                                             │
```

**验收标准**
