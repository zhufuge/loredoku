本版把「占几格」从「每次放置」搬回「资源形态」：同一个形态每次放都一样大，作者在「资源」页的形态卡片里选「占多格」并填宽高，点「加入地图」后以**左上角第一格**为基准放置；放不下（越过画布边界）就提示而非静默落一半。悬停任一占据格时，同一件物品整体抬手（复用现有动画，不加新动效）。游戏页不放置物品，不改。

## §1 共享层：`AssetVariant` 再带 `w`/`h`（可选）

`DraftAnchorItem`（`packages/shared/src/types/domain.ts:188-202`）自 v0.6.0 起就带 `w`/`h`，渲染层（`layerGeometry.ts:41-58`、`MapAssetLayers.tsx` `MapItemLayer`）按足迹画整个 `w×h` 显示框，命中测试（`hitTest.ts:18-26`、`resolveItemAnchor`）已把任一占据格映射回锚点，擦除（`erase.ts`）和信息抽屉（`EditorInfoDrawer.tsx`）也支持多格。

唯独**编辑器放置端硬编码 1×1**，所以 v0.10.6 把 `w`/`h` 放回形态本身：

- `packages/shared/src/types/domain.ts:113-121` `AssetVariant` 新增 `w?: number; h?: number`（可选，缺省 1×1，避免破 9 处全字面量 `variant()` 夹具与 `satisfies Asset`，兼容旧 bundle 缺字段读处 `?? 1`）。
- `packages/shared/src/types/db.ts:68-79` `AssetVariantRow` 新增 `w?: number; h?: number`。
- `packages/shared/src/constants/asset.ts` 新增 `ASSET_VARIANT_FOOTPRINT_MIN/MAX/DEFAULT`（上限复用画布最大格数 `GRID_SIZE_MAX=24`）。
- `packages/shared/src/assetRules.ts` 新增 `resolveVariantFootprint(variant, assetType?)`：背景强制 1×1，物品按 `w/h` 读并 clamp 到 `[1, 24]`。
- `packages/shared/src/schemas/assetVariant.ts`：`createAssetVariantSchema` / `updateAssetVariantSchema` 新增 `w?: footprintSchema.optional()` / `h?: footprintSchema.optional()`，`.refine` 条件补 `|| value.w !== undefined || value.h !== undefined`。**不加 `.default()`**（default 会让空补丁绕过「至少修改一个字段」的 refine，破坏 `appearance.test.ts` 与 `assetVariants.test.ts` 的空 PATCH → 400 用例）。
- 过期的「v0.7.6 占格已从形态去掉」注释在上述文件里逐条改写；历史迁移 `00035_v076_asset_variants.ts` 不动（AGENTS.md 禁止）。

## §2 服务端：迁移 + repo 读写

- 新建 `packages/server/src/db/migrations/20260101000047_v0106_variant_footprint.ts`：`asset_variants` 加 `w`、`h` 两列，`NOT NULL DEFAULT 1`，`down()` 删列。已实测 `db:rollback` → `db:migrate` 往返。
- `packages/server/src/repository/assetVariantRepository.ts`：
  - `CreateAssetVariantData` / `UpdateAssetVariantData` 新增 `w?: number; h?: number`；
  - `create()` INSERT 带 `w: data.w ?? 1`、`h: data.h ?? 1`；
  - `update()` 条件补 `data.w !== undefined` / `data.h !== undefined`；
  - `toAssetVariant()` 输出 `w: Number(row.w ?? 1)`、`h: Number(row.h ?? 1)`，兼容旧行与旧 bundle。
- `packages/server/src/service/assetVariantService.ts` 与 `assetService.ts` 的首形态创建直接透传，无额外改动（缺字段由 DB default 1 兜底）。
- 命名用 `w`/`h`（与 `DraftAnchorItem` 一致），**绝不叫 `widthCells`/`heightCells`**——服务端测试 `not.toHaveProperty('widthCells'|'heightCells')` 与 `{widthCells: 2}→400` 依赖此。
- bundle 无实体 schema（`BundleAssetsFile = { version; assets: Asset[] }`，读时直接 cast），旧 `assets.json` 缺新字段会得到 `undefined`，导出侧 `{...variant}` 自动带上新字段；读处按 `?? 1` 兜住（同 `PuzzleDraft.clues` 读处 `?? []` 的惯例）。

## §3 Web：API payload + 形态编辑表单

- `packages/web/src/api/assets.ts`：`UpdateAssetVariantPayload` 新增 `w?: number; h?: number`（`CreateAssetVariantPayload` 不变，首形态由服务端按 `defaultTo(1)` 建）。
- `packages/web/src/components/asset/AssetVariantCard.tsx`（形态内联编辑表单，已是 `AssetDetailForm` 里每张卡的内容，无独立弹窗）：
  - draft state 新增 `multiCell`（开关，缺省 `variant.w/h > 1`）、`footprintW` / `footprintH`（缺省 1）；`useEffect([variant.id])` 重置；
  - 仅 `asset.type === 'item'` 时展示「占多格」复选框 + 宽/高两个 `NumberField`（`min 1 / max 24`）；
  - 背景形态强制 `1×1`（历史做法见 `docs/v0.6.1.md:133-135,563-569`）；
  - `handleSave` payload 带 `w/h`（非占多格时写 `1`）；服务端 zod 决定验证，前端不做额外 clamp（`NumberField` 的 `min/max` 已在 UI 层拦）。
- `packages/web/src/hooks/useAssets.ts` 的 `useUpdateAssetVariant()` 直接透传 payload，无改动。

## §4 编辑器放置端：尺寸从选中形态读

- `packages/web/src/components/map-editor/EditorCanvas.tsx`：撤掉旧 `pendingSize` prop；放置与预览框均通过 `resolveVariantFootprint(pendingVariant.variant, pendingVariant.asset.type)` 读尺寸；放置回调改为 `onPlaceItem(coord, w, h, fitsHere)`，`fitsHere = false`（越界）时回传由页面负责提示。
- `packages/web/src/pages/MapEditorPage.tsx`：撤掉旧 `pendingSize` state 与 `onSelectAsset` 里的 `setPendingSize({w:1,h:1})`；`onPlaceItem` 在 `fitsHere === false` 时 `toast.error('这个形态占的格子放不下，请换一个位置')`，否则按 `w ?? 1 / h ?? 1` 调用 `editor.placeItem`；背景形态走 `placeBackground`（强制 1×1）。
- 左上角 = 点中的那个格子（即锚点），`fits()` 不通过就不落半块。
- `editorStore.placeItem` / `erase.ts` 已按 `w×h` 足迹写入/擦除，**不用改**；`PuzzleEditorPage.tsx` 只读 `onPlaceItem={() => undefined}`，**不用改**。

## §5 联动动效：不加新动画

用户要求「鼠标触碰一个格子时该格子物品触发动效，另一个格子也会触发」——现有机制已满足：`MapItemLayer` 按 `w×h` 画一整张显示框，`hover` 命中任一占据格整体抬手（`ITEM_HOVER_LIFT_PX=4`，`ITEM_HOVER_TRANSITION_MS=120`），名称提示也随整体走；命中测试按锚点把点映射回同一件物品。不加新动画，游戏页只读跟随。
