# v0.10.8 — 方格大小上限回到抽屉；标尺行列符号可配

> **状态**：已实现（2026-11-14）
> **来源**：用户原话（两条，同一条消息）——
> 「v0.10.8 地图为什么没有cellsize配置了，放出来作为上限配置。主题添加标尺行列符号配置，默认'R''C'，可更换其他字符，如"行""列"」

---

## §0 范围与口径

| 事 | 用户说了吗 | 落点 |
| --- | --- | --- |
| ① 把「方格大小」放回地图基本信息抽屉，作为**上限** | 是（「放出来作为上限配置」） | §1–§3 |
| ② 主题风格加**标尺行列符号**配置，默认 `C` / `R` | 是（「主题添加标尺行列符号配置」） | §4–§6 |

**符号与轴的对应用户写的是「默认 'R' 'C'」，实际列用 `C`、行用 `R`** —— 与既有标尺上一直印着的 `C1…` / `R1…` 一致，不按字面顺序换。

---

## §1 问题：方格大小从界面消失，但语义一直是「上限」

v0.10.3 把 `style.cellSize` 从「定值」降级成「上限」（`effectiveCellSize` = `min(作者值, 按窗口算出的自适应值)`），同时**把抽屉里那一整行撤掉了** —— 字段、schema 与 78 张存量图的数据都没动，只是不再有入口。

结果是一个尴尬的中间态：作者**看得到**旧图被压在一个上限上（24×24 在 1280×800 下格子只有 12px），却没有任何地方能改这个数。撤行那次的理由是「新图一律自适应」，但存量图的作者需要能把这个上限松开。

---

## §2 做法：一行「方格大小上限」

`packages/web/src/components/map-editor/MapInfoDrawer.tsx` 的「画布」段落，在「画布尺寸」下面加回一行：

- 标签叫 **「方格大小上限」**（不是 v0.10.3 之前的「方格大小」）—— 标签本身就要说清它是上限，不能靠提示语。
- `NumberField id="map-info-cell-size"`，范围 `MAP_STYLE_CELL_SIZE_MIN` ~ `MAP_STYLE_CELL_SIZE_MAX`（32 ~ 240）。
- 写入走 `clampCellSize`，与渲染侧 `resolveMapStyle` 同一把尺。
- 右边一枚 ↺ 按钮：`patch((current) => ({ ...current, cellSize: null }))` —— `null` = 没有上限，完全按窗口自适应；已经是 `null` 时按钮 `disabled`。
- 提示语分两种情形（`cellSizeHint`）：
  - 没设上限：`当前没有上限，完全按窗口自适应（本次算得 {autoCellSize}px）。`
  - 设了上限：`当前上限 {n}px：窗口大时最多长到这么宽，窗口小时会跟着缩小（本次自适应值 {autoCellSize}px）。`

**为什么需要把 `autoCellSize` 传回抽屉**：`EditorCanvas` 的自适应 pass 才知道当前窗口算出多少 —— 不显示这个数，作者填上限时是瞎填的。`MapEditorPage` 新增 `const [autoCellSize, setAutoCellSize] = useState(DEFAULT_CELL_SIZE)`，接到 `EditorCanvas` 已有的 `onAutoCellSize` 回调上，再作为 `MapInfoDrawer` 的 `autoCellSize` prop 传下去。这个值**只用于提示与按钮 title**，不参与任何渲染决策 —— 真正生效的格子边长在画布内部算（`effectiveCellSize`）。

## §4 问题：标尺前缀写死在 `ruler.ts` 里

`buildRulerGlyphs` 里原本是 `const prefix = axis === 'column' ? 'C' : 'R';`，`rulerLabelWidth` 里也写死 `C${'9'.repeat(digits)}`。

对中文地图来说，「C1 / R3」和「列1 / 行3」是两种完全不同的读法，而标尺是玩家在棋盘上定位格子的**唯一**参照。写死意味着主题没法统一自己的说法。

---

## §5 做法：`style.ruler.columnSymbol` / `rowSymbol`

- `packages/shared/src/constants/map.ts`：`MapStyleRuler` 加 `columnSymbol: string` / `rowSymbol: string`；新增 `MAP_STYLE_RULER_SYMBOL_MAX_LENGTH = 4`（再长就不是「前缀」而是句子了）。
- `packages/shared/src/constants/region.ts`：`DEFAULT_MAP_STYLE.ruler` 补 `columnSymbol: 'C'` / `rowSymbol: 'R'`。
- `packages/shared/src/schemas/mapDraft.ts`：两个字段 `z.string().max(4).default(...)`。**允许空串** —— 只显示数字也是一种读法。
- `packages/web/src/lib/ruler.ts`：
  - `buildRulerGlyphs` 入参新增 `symbol?: string`，`const prefix = symbol ?? (axis === 'column' ? 'C' : 'R');`（默认值兜住所有没地方传的调用）。
  - `rulerLabelWidth` 新增第三参 `symbols?: readonly string[]`：**逐个真实候选算宽度再取最大**。这条很关键 —— `列` 是全角（1em），`C` 只有约 0.62em，按字符个数比较会把两字前缀算窄，行条就会把标签切掉半截。
- `packages/web/src/components/map/MapRulerStrips.tsx`：`rulerLabelWidth(gridSize, rulerMaxFont, [style.ruler.columnSymbol, style.ruler.rowSymbol])`；两个 `buildRulerGlyphs` 各传自己的 `symbol`，`useMemo` 依赖数组补上对应字段。
- `packages/web/src/lib/mapStyle.ts`：新增 `clampRulerSymbol(value, fallback)`（非字符串回退默认值，超长截断到 4；空串保留）。
- `packages/web/src/lib/themeStyleFields.ts`：`WRITE_SPECS` 加两行 `kind: 'text'` + `maxLength` + `allowEmpty: true`；`FIELD_HINTS` 加两句；`ThemeStyleField` 与 `WriteSpec` 各加 `maxLength` / `allowEmpty`，并在 `THEME_STYLE_FIELDS` 的 map 里透传。
- `packages/web/src/components/theme-overview/ThemeStyleDialog.tsx`：兜底文本分支支持 `maxLength` 与 `allowEmpty` 两个属性。

## §7 没做的

- **没给「标题」加符号**：只改了行列前缀，标签与区域名不动。
- **没做符号的「恢复默认」按钮**：留空即可回到「只显示数字」，但回到 `C`/`R` 要自己打。两个字符，不值一个按钮。
- **没让符号随语言自动切换**：不引入 i18n，作者显式给。
- **没动物品展示偏移**（`offsetX` / `offsetY`）：它们本来就按格记（`0.5` = 半格），语义已经与格子同口径，不属于 v0.10.7 那批「像素偏移」。
- **没给 `cellSize` 加「恢复默认值」**：↺ 的语义是「清除上限 = 完全自适应」，比「回到出厂 150」更接近作者意图。
