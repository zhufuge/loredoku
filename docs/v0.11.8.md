# v0.11.8 — 注释清理：只留契约与原因

## 0. 范围与口径

一句话：**两轮手工清理，只动注释**。第一轮删「原来 → 现在」的过程史，第二轮删裸版本
前缀和只存在于注释里的 Tailwind 类名；代码、字符串、JSX 文本、测试标题、行尾一律不动。

口径六条：

1. **注释写「改这里会坏什么」和外部约束，不写「哪个版本改的」**。版本履历归 git；
   注释里只留仍然成立的规则、边界和原因。
2. **能解析的引用保留**：`docs/vX.Y.Z.md §N`、行号范围、需求编号（`FEAT-*` /
   `SPEC-*` / `CONS-*` 等）都留着，它们是回查文档的索引；只删行首那个裸的 `vX.Y.Z：`。
3. **迁移文件豁免**：`packages/server/src/db/migrations/` 下的注释按历史原样保留，
   迁移的职责就是记录变更。
4. **测试标题里的版本字符串不动**：那是用例名，不是注释。
5. **不跑 formatter、不转行尾**：`core.autocrlf=true` 下工作区 CRLF 是检出形态，
   不做整文件重写。
6. **删后没有信息就整块删**；只剩旧状态、旧名字、旧布局的段落，不留。

AST 对比的做法：先用 `git diff --name-only HEAD` 列出改动文件，`git show HEAD:<path>`
把 HEAD 版本落到临时目录，TS 用 `ts.createPrinter({ removeComments: true })` 打印后压缩

空白后归零。

## 4. 保留

- **697 行 `docs/§` 锚点**：可解析，保留；其中 16 处同时是段标题。
- **41 行迁移文件里的版本**：迁移是历史重放，按规则豁免。
- **约 1,289 块未贴声明的 JSDoc**：要判断 `/** */` 后面是不是声明，得走 AST；手工删
  容易误伤对象字面量和类型字面量，这一轮不碰。
- **测试标题与字符串里的版本号**：不是注释，逐字保留。
- **中英文混排**：不强行统一，避免把一次注释清理变成翻译工程。

## 5. 没做的

- 不写自定义的 comment-lint 脚本：这一轮仍是手工 + 子代理；通用的 `oxlint` 另行接入
  （见第 6 节），两者不是一回事。
- 不做 JSDoc 位置迁移：需要 AST，且收益主要在 IDE / 文档生成，和这一轮的「删过程史」
  是两件事。
- 不升 `package.json` 的版本：仓库三个 workspace 一直是 `1.0.0`，版本只体现在
  `docs/` 与提交信息里，沿用这个做法。
- 不做注释密度指标：密度是抽象质量的症状，不是目标。

## 6. 静态检查：oxlint

`oxlint@1.94.0` 装在根 devDependencies，配置在 `.oxlintrc.json`，只做通用静态检查，
不承担「注释风格」检查。

- 插件显式声明 `eslint`、`typescript`、`react`、`unicorn`、`import`、`oxc`。
- 环境不写死：基础 `es2024`，再用 `overrides` 按目录给 `browser`（`packages/web/src/**`）、
  `node`（`packages/server/**`、`packages/web/scripts/**`、根 `scripts/**` 等）和
  `vitest`（`**/*.test.ts(x)`、`**/test/**/*.ts`）。
- 分类：`correctness` 为 error，`suspicious` 为 warn。
- 规则取舍：
  - `no-unused-vars` 保持 warn，忽略 `^_` 开头的参数/变量，`caughtErrors: none`。
  - `react-hooks/exhaustive-deps` 保持 warn；「换记录才重置」的 effect 与
    `GameSource` 的 manifest 依赖用行内 `oxlint-disable` 写明理由，其余按依赖修。
  - 关闭 `react/react-in-jsx-scope`（自动 JSX runtime 下是误报）和 React Compiler 系列
    （`set-state-in-effect`、`refs`、`preserve-manual-memoization` 等）；本仓是 React 18。
  - 不再全局关闭 `no-control-regex`、`no-useless-spread`、`no-useless-fallback-in-spread`、
    `prefer-add-event-listener`、`preserve-caught-error`：个例改掉或单点抑制。
  - `no-underscore-dangle` 只放行 `__dirname` / `__PLAYER_BUNDLE_CODE__`；
    `import/no-unassigned-import` 放行 CSS 与 `dotenv/config`；
    `import/no-named-as-default-member` 关闭（axios 默认导出互操作）。
  - `GameSource` 的 `react/hooks`：在工厂块和四个调用点用行内注释抑制，理由写在注释里，
    而不是把整条规则关掉。
- 脚本：`npm run lint`（`oxlint`）、`npm run lint:fix`、`npm run lint:deny`
  （`--deny-warnings`，CI 门禁）。

## 7. 极简压缩（第三轮）

用户要求「极简」，口径定为：**每个注释块含定界符不超过 3 行，优先 1 行**。

- 起点：525 个文件、5,097 块 / 19,164 行；超过 3 行的 2,059 块 / 15,624 行（81.5%）。
- 终点：5,084 块 / **5,893 行**，平均每块 1.16 行，**0 个超过 3 行的块**。
- 保留：`docs/...md §N` 锚点、需求编号、`必须/不得/否则/回滚/边界/单位` 等硬约束、
  `oxlint-disable` / `@deprecated` / `// SAFETY:` 等指令注释、测试标题字符串。
- 删掉：复述代码、分区横幅、重复文件头、示例与叙事性长文。
- 方法：先做无损空白重排（拼接块内文字、去 `*` 前缀，不丢词），再用抽取式摘要
  压到 1 行，最后手工处理 21 个指令/锚点块；迁移文件的 41 块也一并压成单行。
- 校验：对 444 个改动文件做「去注释后打印 AST」对比，`checked=444, bad=0`；
  `npm run lint` 0 errors / 0 warnings；`npm run typecheck` 通过；三包测试全过。
  期间发现并修正 `MapGameLayers.tsx` 一处位于三元表达式内的 JSX 注释写法
  （`{/* ... */}` 在表达式位置非法，改回普通块注释）。
